本次更新（1.18.0）
- 桌宠小猫（伙伴出门后在桌面上的那只）：
  - 直接喂它：把小猫面板里的小鱼干拖到桌面小猫身上，或右键选「喂一条」，小猫会低头吃鱼（新的 6 帧进食动画）；喂饱了会冒个气泡告诉你明天再来；
  - 想放哪就放哪：轻轻放下就停在原处，可以趴在窗口边、Dock 上方或菜单栏下面；用力一甩会滑行并在屏幕边缘弹回；位置会记住，拔掉显示器或改分辨率后自动回到屏幕内；
  - 双击小猫会蹦一下（新的 6 帧跳跃动画）；
  - 小猫面板总是弹在小猫旁边，不会挡住它；旁边放不下时放到上方或下方并自动缩小；
  - 摸摸时的小爱心和闪光现在会正常显示。
- 跟随打字（显示与字体 ›「桌宠跟随打字」，默认关闭）：
  - 伙伴出门时，你在任何应用里打字，小猫都会跟着敲键盘，停手约 1 秒后恢复；
  - 只检测“有按键”这件事，不记录、不保存、也不发送按了哪个键；
  - macOS 需要在「系统设置 › 隐私与安全性」允许「辅助功能 / 输入监控」，设置里有「去授权」按钮，授权后回到应用即可生效；未授权或关闭时，小猫只跟随你在小屋窗口里的打字。
- 菜单栏 / 托盘与 Dock：
  - macOS 菜单栏常驻小图标，图标随状态变化（专注 / 暂停 / 播放 / 小猫），专注或休息时旁边显示剩余时间；
  - 菜单可以直接播放 / 暂停音乐、下一首、开始番茄钟 / 暂停 / 继续专注、喂小猫一条小鱼干、打开小屋日记；
  - 专注时 Dock 图标显示剩余分钟和进度条，一轮专注结束时 Dock 弹跳一下；
  - Windows：专注进行时也会显示托盘图标；任务栏按钮显示专注进度和小图标，专注结束且窗口在后台时会闪烁提醒。
- 新美术：打字、进食、跳跃的像素动画，菜单栏 / 托盘图标（macOS 模板图标与 Windows 图标）。
- 修复：
  - 窗景：切换雨天 / 雪夜窗景或开启真实天气时，窗外的云、雨、雪不再跳动或来回抽搐，过渡连续平滑；

已在 1.14.2 中加入：macOS 自动更新

- macOS 自动更新：发现新版本后在后台下载，按发布页公布的 sha512 校验后解压备用，同时核对版本号和应用标识。之后点「重启安装」会替换应用并打开新版本；不点的话，下次退出小屋时静默替换，下次打开就是新版本。不会强制重启，「有新版本时自动下载」可以在 设置 › 关于 里关掉。
- 修复「已经装了新版，却还显示旧版本、还提示更新」：macOS 关掉窗口后，小屋仍在后台运行（桌宠、动态桌面、计时都在后台继续）。这时用 DMG 覆盖应用再打开，系统唤起的还是旧进程。现在重新打开时，小屋会发现磁盘上已经是新版本，自动重启到新版本。窗口正开着时，设置 › 关于 会显示「已安装 vX，重启后生效」，并提供「重启到新版本」按钮。
- 无法自动替换时，例如直接从 DMG 里运行、没有放进「应用程序」文件夹，或者没有写入权限，会说明原因，并继续提供「下载安装包」。

从 1.14.1 及更早版本升级（macOS）
- 旧版本还没有自动更新，这一次需要手动安装（1.14.2 及之后的用户会自动收到本版本）：先在菜单栏选 心流小屋 › 退出（⌘Q）完全退出，再打开 DMG，把心流小屋拖进「应用程序」替换。从 1.14.2 开始，之后的版本都会自动更新。

macOS 自动更新的验证范围
- 自动化测试覆盖：
