心流小屋 1.14.0：交互全屏、黑胶唱机与入门词书。

本次更新
- macOS 使用原生全屏空间；全屏与正常 / 沉浸模式独立切换。全屏仍可操作唱片、歌单、学习和对话框，沉浸保留常驻的「显示工具」与退出入口。
- 修复全屏样式隐藏全部对话框和学习面板的问题，以及沉入桌面尚未完成时退出的异步竞态。Esc 优先关闭对话框或沉浸，再退出全屏；F11 切换全屏。
- 唱机融入原有黑胶材质、唱针和专辑封面；音源选择与布置小屋集中到设置，保留拖拽放盘、唱机特写、队列和唱片自定义。
- 学习加入日常小事、工作交流、音乐生活三本原创入门词书，每本 6 词。支持预览、每日新词额度、FSRS 学习 / 复习引导及 TSV / JSON 本地导入预览。沿用现有调度器和已保存进度；这些不是完整考试词库，不支持 Anki .apkg 或第三方调度历史导入。
- QQ 歌单读取区分账号失效、部分读取失败和确认空列表；补查「我喜欢的音乐」，保留已成功读取的歌单并提供重试。

验证范围
- 自动化使用隔离配置和测试数据；真实 QQ 账号、实际用户安装环境及多显示器全屏体验不在已完成的本机验收范围内。
- 发布流水线为 Windows x64、macOS arm64 和 x64 打包，并要求实际打包客户端通过全屏、沉浸、对话框和学习入口检查。
- 不迁移或重置收藏、账号与学习记录，不清除用户缓存。

已知限制
- 音乐仍受平台账号、版权、地区和服务状态影响；不绕过 DRM 或付费权限。
- Apple Music 订阅播放 / MusicKit 接入尚未完成，保留现有元数据导入与系统播放器能力。
- 本轮未升级依赖；此前桌面依赖审计的 15 项告警（9 中危、6 高危）仍需专门处理，不能视为已修复。根项目许可证与 GPL 组合发行义务仍待明确。
- macOS 尚未完成开发者签名与 Apple 公证，Windows 尚未配置发布者签名。

下载与升级
- 按设备选择 macOS arm64 / x64 或 Windows x64 安装包。SHA256SUMS.txt 用于核对安装包校验值。
- 可在「设置 → 关于」检查更新。macOS 与 Windows 便携版采用手动下载安装包，Windows 安装版提供应用内更新。
