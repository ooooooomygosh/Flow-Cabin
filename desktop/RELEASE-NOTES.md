# 心流小屋 · 发布说明

最新版本：1.21.5

## 1.21.5

六个方向各过了一遍。界面没换皮，但几处细节真的变好了。

- **唱片现在真的会飞。** 之前双击唱片，它会原地不动地停 720 毫秒然后凭空出现在唱盘上——那段飞行其实没发生。现在它沿着 8 段整像素的弧线飞过去。
- **最小化之后奶糖不会偷偷跳。** 之前动画停了，两秒一次的重同步又把它唤醒。
- **关掉弹层，焦点会回到原处。** 用键盘走完专辑网格再关掉弹层，焦点不再整个丢失。
- **报错提示看得清了。** 错误 toast 的对比度从 3.11（低于 AA）提到 5.41，焦点环全应用统一成虚线灯环。
- **数据层修掉十三个真实缺陷。** 空值不再被当成 0、备份导入中途失败不再留下半份数据、统计不再出现假日期。
- **宣传页轻了 15MB。** 首屏原本要下 16.4MB 字体，改走系统中文字体后降到 1.57MB。
- **下载地址跟着仓库改名一起更新。** 从 `album-web` 改名成 `Flow-Cabin`，下载页、更新检查与发布目标都已指向新地址。
- **许可证明确了。** 根项目采用 GPL-3.0-only，与随包分发的 Simple Music 模块自洽。

### 验证范围

桌面端 354 项、根项目 541 项（540 通过 / 1 跳过）测试通过，五个入口的生产构建产出，宣传页浏览器回归 18/18；两处动效修复在真实 Chromium 下复测：飞行姿态 2 → 9，后台 2.3 秒内不再复活。详见仓库内 `docs/audit/polish-2026-10/INTEGRATION.md`。

### 未变的边界

- 安装包仍未完成商业签名与公证；QQ 音乐 / 网易云仍走非官方接口；macOS 的中文输入法组合仍未在真机上验收；仍没有 Windows ARM64 与 Linux 安装包。

## 1.21.4

这次更新把本机 Codex CLI 从“能打开”修到“能稳定完成一次小屋请求”，同时收紧了智能唱片机的歌单契约。

- **保留你自己的 Codex 配置。** 小屋仍读取本机 `codex exec` 的最终回答，但不再强制清空用户配置，避免自定义 provider、模型和已登录账号失效；`config.toml` 里 `env_key` / `env_http_headers` 声明的凭据变量会保留，请求仍会关闭通知钩子、MCP、插件与规则文件，并在临时目录里以只读 sandbox 运行。
- **取消和退出都不留任务。** 切换 API Key、清空 AI 设置、关闭智能唱片机、请求超时或退出小屋时，会取消正在运行的本机 Codex 任务；stdin 提前断开也不会再让主进程崩溃。Windows 使用 `taskkill /T` 结束整棵 `cmd.exe → node → codex` 进程树。
- **Windows 启动器更可靠。** `.cmd` 启动器改由 `cross-spawn` 逐参数转义，路径含空格或 npm shim 不会再被 shell 拆开；同时修复 GUI 启动时的 Node PATH 与分号分隔路径，并保留只读取 `--output-last-message` 的边界。
- **歌单必须是一张完整的歌单。** 提示词和解析器都要求 6–14 首；少于 6 首、JSON 不合格或连接失败时会明确回退本机唱片架推荐，不再把两三首当成完整结果。
- **依旧不展示思考过程。** JSONL 里的 reasoning、工具事件和临时会话不会进入信件、歌单或日志；思考控制仍只走允许的固定模板。

## 1.21.3

这次更新把 AI 连接从“自己拼接口”改成固定供应商模板，并让桌面版直接调用本机已登录的 Codex CLI；DeepSeek 的默认模型与思考模式也一并修正。

- **供应商改成固定模板。** 设置里直接选择 DeepSeek、OpenAI、OpenRouter、Ollama、LM Studio、本机 Codex CLI 或自定义接口；预设地址只读，不再需要手动拼 `/v1/chat/completions`。Ollama 与 LM Studio 使用本机服务，不需要 API Key。
- **DeepSeek 默认 `deepseek-flash` 且关闭思考。** 官方接口的请求会自动带上 `thinking: { type: "disabled" }`；旧版保存的 `deepseek-chat` / `deepseek-reasoner` 会在升级时迁到 `deepseek-flash`，不需要用户重新配置。
- **桌面版可以直接调用本机 Codex CLI。** 小屋会在临时目录运行 `codex exec`，并通过 `--output-last-message` 只读取最后一条回答。思考过程、工具调用、JSONL 事件与会话文件不会显示、保存或写进歌单 / 信件；网络请求仍由你本机 Codex CLI 已登录的账号和模型配置发出。网页版不提供这个模板。
- **本地模型不需要 Key。** Web 与桌面版都支持 loopback 的 Ollama / LM Studio；桌面版通过主进程转发，不把本地服务当成需要密钥的云服务。
- **错误提示不再误导。** 如果服务仍返回 OpenAI 结构但正文为空，会明确提示可能是思考 token 占满输出上限，而不是把正常响应误报为“不是 OpenAI 格式”。
- **所有入口共用同一套连接判断。** 连接测试、智能唱片机、自动来信和手动回信都会识别模板、Keyless 本地服务与桌面 Codex；AI 失败时会显示具体原因，并继续保留本机唱片架推荐或本地回信。

- 在只保留 `/usr/bin:/bin` 的模拟 GUI 环境中，本机 macOS Codex CLI 冒烟返回 `FLOW_CABIN_CODEX_GUI_PATH_OK`，确认 Node 路径补全与最终回答读取都成立；单元测试另覆盖 Windows npm `.cmd` shim 与分号分隔 PATH。

### 已知边界

## 1.21.1

这次更新修好奶糖的「普通打字不灵敏」，把手动授权收敛为 macOS 真正需要的一项，并让智能唱片机按计划编排整张歌单。

- **普通键盘输入改用可靠的全局层。** macOS 不再经过会漏掉普通 key-down 的 session hook，改为应用内的 HID listen-only event tap：普通字母、数字、Shift / Command、鼠标按下与中文输入法里的按键都能触发奶糖。事件回调只做固定分类和计数，不在回调里读写文件或操作界面。
- **只申请「输入监控」。** 删除了不必要的辅助功能检查和授权步骤。首次引导、更新向导与「设置 › 键鼠陪伴」现在都是一步授权，仍以「本次确认」是否增长作为端到端验证。
- **减少反复授权。** macOS 构建改用稳定的签名身份，TCC 授权绑定证书而不是每次变化的 ad-hoc CDHash。设置里新增「输入一直没反应？修复输入监控授权」，只在用户确认后重置，不会在启动时自动清除授权。
- **更新包校验签名。** 自动更新会拒绝证书身份与心流小屋不一致的包，避免未来误换签名后静默破坏已授权状态。
- **更新向导继续保留。** 版本变化时会展示从上次确认版本到当前版本的全部用户变化，并重新检查音源、键鼠陪伴、房间与试听；本次会明确列出输入层和权限的变化。
- **智能唱片机改排完整歌单。** 说一句「学习 50 分钟，帮我搭配音乐」，AI 会按计划生成一张可包含唱片架之外歌曲的完整歌单，不再只从唱片架选 1–3 张。生成后可以「只收进唱片架」，或「收进唱片架并开始专注」；歌单以普通 playlist 记录保存，播放时沿用自动匹配音源。严格 JSON 只接受 `title`（歌单名）、`description`（编排说明）、`minutes`（15–180 分钟）、`activity`（活动类型）、`tracks`（按播放顺序的 6–14 首曲目）和 `autoplay`（是否自动播放）；曲目只保留 `title` / `artist` / `album`，模型提供的平台 id 会被丢弃。

## 1.21.0

这次更新把「设置是否真的生效」和「奶糖在桌面上怎么陪你」重新串成了一条完整的日常。

- **每次升级都会重新确认一次。** 应用会从上次完成引导的版本开始，逐条列出期间所有版本的变化；很久没回来的话，会一次看到从 1.18 到 1.21 的全部内容。音源、通知、输入监控、房间与伙伴、试听会在同一轮里逐项检查。中途关掉也没关系，下次打开会接着完成。
- **键鼠陪伴有了清楚的一级入口。** 在「设置 › 键鼠陪伴」里开关、授权和查看今天的键盘 / 点击次数；即使焦点不在小屋，奶糖也会回应。记录只保存次数与时间戳，不保存按键内容、鼠标坐标、应用名或窗口标题。
- **陪伴记录走进统计、日记与来信。** 今日键盘 / 点击次数、连续陪伴天数和最近 7 天趋势会和专注、听歌、手记放在一起，成为可以回看的日常。
- **桌宠有了 Bongo Cat 风格的小面板。** 看今天的计数、喂一条小鱼干、开始专注、调声音、换配饰，或一键打开小屋和专注画面；面板贴着奶糖，不占整块桌面。
- **智能唱片机。** 直接说「学习 50 分钟，帮我搭配音乐」，小屋会从你的唱片架里按顺序选出 1–3 张，并用严格 JSON 契约校验选片。确认后开始专注、把第一张放上唱机；你可以立即播放，也可以先只放盘、稍后自己按播放。

已在 1.14.2 中加入：macOS 自动更新

- macOS 自动更新：发现新版本后在后台下载，按发布页公布的 sha512 校验后解压备用，同时核对版本号和应用标识。之后点「重启安装」会替换应用并打开新版本；不点的话，下次退出小屋时静默替换，下次打开就是新版本。不会强制重启，「有新版本时自动下载」可以在 设置 › 关于 里关掉。
- 修复「已经装了新版，却还显示旧版本、还提示更新」：macOS 关掉窗口后，小屋仍在后台运行（桌宠、动态桌面、计时都在后台继续）。这时用 DMG 覆盖应用再打开，系统唤起的还是旧进程。现在重新打开时，小屋会发现磁盘上已经是新版本，自动重启到新版本。窗口正开着时，设置 › 关于 会显示「已安装 vX，重启后生效」，并提供「重启到新版本」按钮。
- 无法自动替换时，例如直接从 DMG 里运行、没有放进「应用程序」文件夹，或者没有写入权限，会说明原因，并继续提供「下载安装包」。

从 1.14.1 及更早版本升级（macOS）
- 旧版本还没有自动更新，这一次需要手动安装（1.14.2 及之后的用户会自动收到本版本）：先在菜单栏选 心流小屋 › 退出（⌘Q）完全退出，再打开 DMG，把心流小屋拖进「应用程序」替换。从 1.14.2 开始，之后的版本都会自动更新。
