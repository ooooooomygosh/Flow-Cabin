心流小屋 1.15.0：界面统一打磨，动画帧率封顶 60，更省电。

本次更新（1.15.0）
- 表单与下拉框：
  - 修复下拉框中间出现大三角、挡住文字的问题（当前任务、词书、每天新词、音质、歌曲过渡等）；
  - 全部输入框、下拉框和日期框统一成深色内凹样式，右侧是小像素箭头，日历图标改成暖琥珀色。
- 房间：
  - 小猫说话时，气泡浮在木屋唱机上方，不再被面板盖住，并优先往右侧弹出；
  - 右上角的专注胶囊改成低调的深色小牌，运行时只亮一盏小灯；打开专注面板时不再重复显示倒计时；
  - 沉浸 / 全屏切换条固定在最上沿或标题栏里，不再压住唱片架上的小唱机；
  - 唱片架空格改成内凹的木格，封面铺满封套，「歌单」角标变小。
- 木屋唱机：
  - 控制盘改成胡桃木配黄铜边的深色转盘，中间是琥珀色播放键，播放时呈按下状态；
  - 「顺序 / 随机」和「曲目」排成转盘下方的一行等高控制条，开关亮绿灯；窗口较窄时「曲目」自动换到下一行；
  - 歌名、歌手、状态拉开层次，音质用小徽章标出；歌名和括号之间补上空格；
  - 唱机特写的唱臂线条更干净，曲目列表留出底边并有像素滚动条，唱片箱封面放大。
- 专注面板：
  - 统计图和 18 周热力图放进深色底板，墙上海报不再透出来；热力图空格有描边，格子清晰可数；
  - 未解锁的配饰和窗景显示虚线框和小锁；学习页的按钮与输入框等高对齐。
- 我的歌单与设置：「我喜欢」改成整行横幅；歌单封面加像素画框，标题单行省略；每个音源前有状态灯。
- 性能：
  - 所有动画统一由一个时钟驱动，帧率封顶 60，高刷新率屏幕不再空转；配置较低的电脑上唱机特写为 30 帧；
  - 窗口最小化或隐藏时动画全部暂停；只是切到别的窗口时照常转动；
  - 雨、雪、星光等效果改用更省显卡的方式绘制，去掉了几处每帧重算的大面积模糊；桌面壁纸的帧率限制现在真正生效（30 帧，用电池时 10 帧）。

已在 1.14.4 中加入：
- QQ 音乐上本来就有的歌，现在更容易匹配并播放（例如陶喆《月亮代表誰的心》）。原因是 QQ 在短时间收到一串请求后，会暂时拒绝搜索（错误码 2001），而旧版本被拒后会在 1.2 秒内把同一个请求再发 5 次，还会把简体、繁体、预加载的搜索各再来一遍，拒绝因此一直持续。现在：
  - QQ 自家客户端使用的两种完整搜索方式轮流尝试，被拒后各再试一次，最后才用搜索框联想；
  - 每次搜索至少间隔 0.3 秒，被拒后间隔 1.2 秒；同一首歌的重复搜索只发一次，被拒的结果 20 秒内不再重复去问；
  - 一次取 20 条结果，原唱不会被翻唱版本挤出去；用「歌手 + 歌名」找不到时，再单独搜歌名，仍会核对歌手、专辑和时长；
  - 搜索失败时，唱机会说明是哪个平台出了问题，不再显示「QQ_SEARCH_FAILED」这样的原始代码。
  - 新增一项在线检查：在 GitHub 上用真实 QQ 音乐搜索 10 首歌（含繁体歌名），走的是小屋自己的匹配流程，10 首都能匹配到正确的版本。检查中 QQ 曾连续拒绝搜索，新的方式仍全部找到了。
- 换歌不再卡顿：当前这首开始播放后，下一首就会提前匹配并缓冲好，结束时直接接上；缓冲失败会跳过这首，改为准备再下一首。
- 新增「歌曲过渡」（设置 › 音源）：可选无缝衔接，或淡入淡出 3 / 6 / 10 秒。
- 唱机改成随身听样式：琥珀色背光屏显示封面、歌名、进度和剩余时间；奶白色像素转盘上是待播、上一首、下一首、取下唱片和中间的播放键；循环和随机是带指示灯的按键。
- 播放歌单时，唱机、特写、桌面小组件和系统媒体控件都会显示当前这首歌的封面。
- 桌宠跟着歌曲的节拍律动：从鼓点识别速度和拍点，每拍跳一下、落地时点头，音量只影响跳多高；桌面上的桌宠窗口用同一个节拍。听 lo-fi 时跟 lo-fi 的速度。边听歌边跳舞时，桌宠不会突然走开。

已在 1.14.2 中加入：macOS 自动更新

- macOS 自动更新：发现新版本后在后台下载，按发布页公布的 sha512 校验后解压备用，同时核对版本号和应用标识。之后点「重启安装」会替换应用并打开新版本；不点的话，下次退出小屋时静默替换，下次打开就是新版本。不会强制重启，「有新版本时自动下载」可以在 设置 › 关于 里关掉。
- 修复「已经装了新版，却还显示旧版本、还提示更新」：macOS 关掉窗口后，小屋仍在后台运行（桌宠、动态桌面、计时都在后台继续）。这时用 DMG 覆盖应用再打开，系统唤起的还是旧进程。现在重新打开时，小屋会发现磁盘上已经是新版本，自动重启到新版本。窗口正开着时，设置 › 关于 会显示「已安装 vX，重启后生效」，并提供「重启到新版本」按钮。
- 无法自动替换时，例如直接从 DMG 里运行、没有放进「应用程序」文件夹，或者没有写入权限，会说明原因，并继续提供「下载安装包」。

从 1.14.1 及更早版本升级（macOS）
- 旧版本还没有自动更新，这一次需要手动安装（1.14.2 及之后的用户会自动收到本版本）：先在菜单栏选 心流小屋 › 退出（⌘Q）完全退出，再打开 DMG，把心流小屋拖进「应用程序」替换。从 1.14.2 开始，之后的版本都会自动更新。

macOS 自动更新的验证范围
- 自动化测试覆盖：
  - 读取 `latest-mac.yml`、选择对应架构的安装包；
  - sha512 不符、版本不符、应用标识不符时拒绝更新，并清理文件；
  - 可以自动替换和不能自动替换的各种情况；
  - 点「重启安装」与退出时安装两种路径；
  - 「磁盘上是新版本」的检测与重启。
- 替换脚本在 Linux 上用临时目录实际运行过，验证了等待旧进程退出、替换和失败时还原。
- 在真实 Mac 上替换「应用程序」里的应用并重新打开，还没有在本机自动化中验证。
- 新增的代码签名完整性检查（codesign --verify）需要在真实 Mac 上确认；如果检查不通过，自动更新会报错并保留现有版本，仍可手动下载安装包。
- 安装包使用 ad-hoc 签名，每次构建签名都会变化，更新后 macOS 可能会再次询问是否允许心流小屋控制「音乐」。

已知限制
- 音乐仍受平台账号、版权、地区和服务状态影响；不绕过 DRM 或付费权限。
- 尚未接入 Apple MusicKit：资料库外的 Apple Music 歌曲需要在「音乐」App 里点一次播放。真实「音乐」App、账户和自动化权限下的表现，还没有在本机自动化中验收。
- 此前桌面依赖审计的 15 项告警（9 中危、6 高危）仍需专门处理。根项目许可证与 GPL 组合发行义务仍待明确。
- macOS 尚未完成开发者签名与 Apple 公证，Windows 尚未配置发布者签名。

下载与升级
- 按设备选择 macOS arm64 / x64 或 Windows x64 安装包。SHA256SUMS.txt 用于核对安装包校验值。
- Windows 安装版和 macOS（放在「应用程序」里）会自动更新；Windows 便携版需要手动下载新版本。
