心流小屋 1.13.0：歌单、唱机、桌宠和专注体验改进（PR #18–23）。

本次更新
- 改善播放状态同步、预加载与账号切换后的缓存处理，优化歌单入口、播放队列和唱片选择反馈。
- 网易云歌单支持分批手动加载，最多保留 5,000 首；缺失曲目可重试，保持原歌单顺序，并防止不完整导入覆盖更完整的本地收藏。
- 大歌单和文件导入提供数量与截断提示；QQ 与 Apple 元数据导入当前的 500 首限制仍明确显示。
- 修复旧 QQ 收藏缺少 mediaMid 时无法解析原曲音源的问题：播放时读取曲目详情补齐，不修改收藏，也不绕过会员、版权或地区限制。
- 改善桌宠显示器适配与动画生命周期，完善学习卡片编辑、搜索和复习状态保存，以及小屋唱机与队列界面。

验证范围与已知限制
- 功能基线 75edba18c8c458d4dd4ceec0b9e28423c57ac2f3 的主分支 CI 已通过。221 项桌面测试、90 项渲染器测试及 73 项浏览器离线回归通过；这些使用测试夹具，不等同于真实账号验收。
- 发布流水线为 Windows x64、macOS arm64 与 x64 构建，并在上传前执行打包客户端检查。Windows 真机、真实平台账号与完整跨版本升级流程尚未完成本轮验收，仍需实际设备验证。
- Apple Music 正式授权、订阅播放与 MusicKit 接入按用户要求暂缓；保留现有元数据导入，不能把它当成 Apple Music 订阅播放。
- 桌面依赖仍有此前审计发现的 15 项告警（9 项中危、6 项高危），包括尚未解决的媒体元数据解析风险；本次未升级依赖，不应视为安全问题已修复。
- 根项目许可证与 GPL 组合发行义务仍待明确。macOS 尚未完成开发者签名与 Apple 公证；Windows 尚未配置发布者签名。
- 音乐可用性取决于平台账号、版权、地区与服务状态；不绕过 DRM、付费权限或平台授权。

升级与校验
- 收藏与专注记录保存在本机，建议先在「设置 › 数据与备份」导出备份。
- 请按设备选择 macOS arm64／x64 或 Windows x64 安装包。SHA256SUMS.txt 提供安装包与压缩包的下载校验值。
- v1.12.0 可从「设置 › 关于」检查更新；macOS 与 Windows 便携版采用手动下载安装包，Windows 安装版提供应用内更新。
