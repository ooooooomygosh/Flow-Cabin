心流小屋 1.14.1：繁体歌名能匹配、Apple Music 资料库外的歌、更清楚的播放模式图标。

本次更新
- 繁体 / 简体不再影响播放匹配：从台湾、香港曲库添加的「討厭紅樓夢」现在能匹配到 QQ 音乐、网易云里的「讨厌红楼梦」。匹配时两种写法视为同一首，搜索会依次尝试简体、原文和繁体，找到能播放的版本就停止。Live、伴奏等版本标记也按同样规则识别，现场版依然不会顶替录音室版。
- 系统 Apple Music（macOS）：先在「音乐」资料库里按简体、繁体分别查找，资料库里有就直接播放。资料库里没有的歌，会用 Apple 曲库找到同一首（从 Apple 曲库添加的唱片直接用原来的曲目编号），在「音乐」App 里打开它，并提示你点播放；之后小屋会同步显示进度。Apple 只允许「音乐」App 用脚本播放资料库里的歌，所以资料库外的歌需要你在「音乐」App 里点一次播放，加入资料库后下次就能直接从小屋播放。
- 播放模式图标换成像素风：
  - 循环：关闭时为暗色，整张循环时高亮，单曲循环时高亮并带「1」。
  - 随机：两条交叉箭头。
  - 歌单里的「随机播放」按钮也换成了同一个图标。
- 检查更新改为读取 github.com 发布页，不再受 GitHub API 每小时 60 次匿名额度的限制（1.14.0 已包含）。

验证范围
- 自动化测试覆盖：
  - 繁简对照与匹配评分；
  - 各写法的搜索顺序；
  - Apple Music 先查资料库、再找曲库并在「音乐」App 打开的流程；
  - 曲库查询参数与曲目编号校验。
- 「音乐」App 的实际脚本控制、自动化授权和曲库页面打开，需要在真实 Mac 上确认，不在本机自动化范围内。
- 繁简转换按单字对照（数据来自 OpenCC）。少数一对多的字（如「发 / 髮」）按最常见写法转换，因此搜索会同时保留原文。

已知限制
- 音乐仍受平台账号、版权、地区和服务状态影响；不绕过 DRM 或付费权限。
- 尚未接入 Apple MusicKit：资料库外的 Apple Music 歌曲不能在小屋内一键直接播放。
- 此前桌面依赖审计的 15 项告警（9 中危、6 高危）仍需专门处理。根项目许可证与 GPL 组合发行义务仍待明确。
- macOS 尚未完成开发者签名与 Apple 公证，Windows 尚未配置发布者签名。

下载与升级
- 按设备选择 macOS arm64 / x64 或 Windows x64 安装包。SHA256SUMS.txt 用于核对安装包校验值。
- 可在「设置 → 关于」检查更新。macOS 与 Windows 便携版需要手动下载安装包，Windows 安装版提供应用内更新。
