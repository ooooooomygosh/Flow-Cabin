# Flow Cabin 2.1 实施与验证记录

基线：公开 v2.0.0 / `91eeda3`。按用户最新意见，原版唱片架仍为默认首页，专辑墙恢复顶部入口；新生活小屋放入明确的 Beta 选择，保存后重启才生效，可切回原版。Beta 采用独立全屏角落，减少全屋物件密度。旧 2.0 验收文档仅作历史记录。

## 验证命令与产物

当前门禁：`npm run qa`；原生打包客户端：`npm --prefix desktop run test:client`。原版和 Beta 双套门禁见 `CONTRIBUTING.md`。不通过删除功能性检查来掩盖 UI 迁移问题。

- 单元测试：桌面407、前端601、移动存储/后端8项通过，共1016项；1项浏览器专用播放日志默认跳过，在CI单独运行。
- 浏览器：Web 收藏8、原生播放桥6、手记6、永久删除4、学习6、AI/来信11、宠物纪念物7、设备设置5、家具交互6（含禁用图形加速的房间/明信片）、生产CSP/50主题切换5，以及真实音频队列/淡入淡出回归。
- 原版回归：主流程68项、专注34项、唱片架11项、主题互动5项；首次收藏读取失败有清晰重试，准备恢复点前不挂载会写入数据的组件。
- 原生 Electron：10条流程，证据 `desktop/test-results/home-v21-native/`；明确是隔离测试 profile。
- 视觉：最终版162张截图，另有早于最后字体优化的270张补充截图。252处关键文字平面与130份宠物轮廓检查无裁切/主要控件遮挡；八主题、昼夜、横竖屏、减少动态均有覆盖。证据 `desktop/test-results/art-v21-review/`。
- Android：专用 API36 AVD；16项原生 instrumentation，WebView/系统栏/键盘/重启证据 `mobile-test-results/home-v21/`。该目录不包含个人账号；这轮模拟器验收早于最后的原版/Beta切换，最终APK另行重新编译签名，未重新启动模拟器。
- 性能：50次主题切换仍只有一个 Pixi 画布，50次角落切换仍是同一播放节点和两个音频 deck；两小时静音生成 WAV 播放已完成（2026-10-23 10:48–12:48 UTC），240次采样、0页面错误、持续播放7206秒，JS堆约12.4–14.4MiB，结束13.7MiB；这是JS堆而非应用总内存。该长测早于最后的原版/Beta与节拍修正，最终候选另做短回归。桌面60fps/手机30fps是渲染目标，不能将构建或截图当作硬件帧率认证。

截图、原生日志和测试报告写入忽略目录，CI报告作为工作流附件保存；README保留原版首页与两张明确标注 Beta 的实际截图。

## 明确边界与发布状态

原版保留六种旧场景；Beta 的雨夜列车和温室切回原版时显示对应的琥珀/林间背景，保存的主题身份保持不变。窗景中的太阳/月亮目前属于插画，昼夜联动调节整体明暗与饱和度。个别展示（如相框自选图片、信箱未读与书架复习数量直接画在全屋家具上）仍以打开对应工具查看为主。真实平台账号覆盖升级、物理耳机/蓝牙/来电、各系统定位授权、真实跨设备漫游尚无足够实测证据，不能标为通过。云同步、中继、多人房间和 Android 跨应用悬浮桌宠保持后续范围。
