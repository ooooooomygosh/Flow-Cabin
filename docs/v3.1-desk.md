# 心流小屋 3.1 · 桌面实物化记录

基线：v3.0.0（`c159f41`）。3.1 不再改信息架构（沿用 3.0 的「唱片架 · 专注 · 日记」和听 → 专注 → 唱片日记的循环），只改**界面的质地**：把网页式按钮、卡片和面板全部换成房间里的实物。方向、材质配方和声音思路来自 [DEsk](https://github.com/fyzugx/DEsk)（MIT，© 2026 The DEsk authors；许可文本在 `public/licenses/DEsk-MIT.txt`，移植的文件头部都写了出处）。规则与已有实物见 [3.1 桌面实物设计规范](v3-desk-design.md)。

## 做了什么

## 移除

- 原版唱片架首页（`ClassicCabinRoom`）和「改用原版」的所有切换、设置项、桌面与 Android 重启通道。旧的首页选择会被忽略。
- 只给原版用的场景互动（`ThemeInteractions`）、旧的 `room2` 家具编辑器、`public/room-scenes/modular/` 与 `thumbs/`（共约 48 MB）。
- 动态桌面（沉入桌面）仍使用旧场景代码，不受影响。
- 返工（首页换成 DEsk 的书桌）后删掉的等距小屋：`CabinHome`、房间画布、三个角落（素材、镜头、导航）、读数、家具小物、旧 LED 台钟、`home/drawer/*`（选择小屋相册、布置托盘）、`shell-model`（顶栏、热点、齿轮菜单）、`useLife`、首页 chrome 样式、正在播放条（`NowPlayingBar` 及其样式），以及只有家具能打开的挂历、植物、茶歇、休息角面板和设置里不再通向任何地方的「布置小屋」。
- 素材：`public/room-scenes/v21/furniture/`（全部家具图集）、各房间的工作角 / 生活角画面与角落坐标、`scripts/art-v21/`。保留各房间的 `shell.webp`（场景选择、动态桌面）、`corners/music.webp`（歌词册背景）和沉入桌面用的平面场景。构建产物从 199.9 MB 降到 140.5 MB。

首页换成书桌后，下列检查测的是已删除的东西，已从回归里去掉（其余检查改走书桌：唱片架铜牌 → 活页夹、唱机铜牌 → 面板、台钟 → 专注、抽屉 → 设置 / 伙伴 / 随手记…，共用 `scripts/settings-actions.mjs` 与 `desktop/test/ui-fixture.cjs` 里的 `lookUp`、`pressSpot`、`openDrawerThing`、`openFocus`、`backToDesk`）。

- 单元测试 `src/home/corner-nav.test.mjs`、`src/home/shell-model.test.mjs`、`src/home/drawer/drawer-model.test.mjs`：被测模块（角落导航、顶栏与热点、旧抽屉）已删除。
- `scripts/android-assets.test.mjs` 不再要求保留 `room-scenes/v21/furniture/pixel/atlas.webp`：家具图集已删除；改为要求保留书桌图片。
- 浏览器冒烟 / 新手引导 / Electron：首页 `.cabin-home.theme-*` 随场景换皮、顶栏伙伴头像显示所选伙伴：书桌不随场景变、也不画伙伴；改查保存的选择和设置里的选中状态。
- `cabin-layout-checks`：顶栏七项的顺序与同行、正在播放条不透明且按键不出界、房间区域四个铜牌不压住正在播放：这些部件已删除；改为书桌后沿、唱片架铜牌、抽屉拉手与窗口按钮的布局检查。
- 浏览器冒烟「沉入桌面时顶栏和正在播放条让位给小组件」：书桌没有这两样。
- `fullscreen-study-checks`、`shelf-ui-regression`、Electron `focus-ui`：「收起工具把铜牌收起」：书桌没有铜牌导轨（收起工具在书桌上目前只留下沉浸工具条，见下方边界）。
- `shelf-ui-regression`「设置只是一个图标」：设置现在是抽屉里的螺丝刀。
- `benchmark-cabin-checks`：三个家具热点（唱机 / 书桌 / 窝）可点并打开对应面板、齿轮抽屉里的「选择小屋 / 布置小屋 / 全部设置」、伙伴头像的 `aria-expanded` 与头像上的配饰：改为书桌入口、抽屉物件和伙伴面板自己的配饰检查。
- `focus-ui-regression`：正在播放条上的「开始这一段」（改用桌宠的开始专注命令）、顶栏在窄窗口里不重叠（改为书桌入口）、Esc 回到铜旋钮（改为回到书桌，抽屉在取出东西时已推回）。
- `beat-sync-regression`：生活角的小猫换成歌词册上的小猫；「平稳音调时回到睁眼 idle、闭眼聆听不超过 2 秒」是房间小猫（PetLife）的行为，歌词册小猫按设计一直保持聆听姿势，删除这两条。
- `home-v21-regression`：正在播放条的歌名、一行歌词、♥、「开始这一段」：改到唱机旁与台钟，「一行歌词」删除（书桌没有歌词行）；50 次切换角落改为 24 次抬头看书柜 / 唱机 / 信箱再低头。
- `home-interactions-regression`：顶栏三入口 / 齿轮四项 / 三个热点标签 / 房间名菜单；工作角任务纸（改为书柜台历打开待办）；挂历记重要日子；布置小屋（撤销、重做、布局文件）；浇花与茶歇；触摸滑动、方向键、数字键、拖动、触控板在角落间移动、角落预加载、记住上次所在角落；无 WebGL 时的房间画面（改为明信片印出书桌）。
- `lyrics-regression`：听歌角歌词本的卡拉 OK 逐字填色、正在播放条的歌词行：两处都已删除；沉浸歌词与桌面歌词的检查保留。
- `room-production-regression`：50 次切换主题只保留一个 Pixi 画布（改为 30 次抬头 / 低头不留胶片和视图）、布置小屋抽屉在安全区内、横屏角落主按钮可点（改为书桌入口在安全区内可点）。
- `devices-ui-regression`：设置里的「布置小屋」打开沉浸场景（改为确认它已不存在）。
- `souvenirs-regression`：伙伴头像的 `aria-expanded`、Esc 把焦点还给头像（改为还给书桌）。
- `interface-mode-regression`：手机上的「房间名下拉」高度（房间名菜单已删除）；顶栏三入口 48 px 改为书桌五个入口在屏内且每边至少 24 px。

## 边界（未实测）

- 在真机上的观感与声音（Android、Windows、macOS）未实测；Android 原生部分的改动（去掉 `restartInterface`）未编译。
- 手写字体用系统楷体（`Kaiti SC`、`STKaiti`、`KaiTi`、`LXGW WenKai`）；没有安装这些字体的机器会回退成无衬线体。
- 纸张折角的「掀起」依赖 `@property`（Chromium、Electron、Safari 16.4+）；不支持的浏览器里折角直接跳到掀起后的大小。
- 专注台历把「今天列表里排到之后日期的任务」在界面上归到「之后」，但桌面小组件、小屋角落的任务卡和明信片仍按「未完成」统计为今天的任务。
- Electron 界面测试需要联网和真实系统钥匙串，部分在无外网的沙箱里不能运行，以 CI 为准。
