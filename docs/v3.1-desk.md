# 心流小屋 3.1 · 书桌记录

基线：v3.0.0（`c159f41`）。3.1 不改信息架构（沿用 3.0 的「唱片架 · 专注 · 日记」和听 → 专注 → 唱片日记的循环），只改界面。规则见 [3.1 书桌设计](v3-desk-design.md)。

## 第一版为什么不行（自审）

3.1 的第一版在等距 3D 像素小屋上面再贴一层 DEsk 式的实物：胡桃木后沿、铜牌、LED 台钟、纸面板、电子管控制台。作者看过后说「差得太多」「各种东西对不上」。逐张截图对照 DEsk 后，问题是：

1. **一屏四五种画风**：像素等距房间、油画质感的角落近景、CSS 画的铜牌和 LED、矢量抽屉物件、纤维纸。DEsk 只有一种：同一个渲染器、同一盏灯。
2. **重复和对不上**：房间画里已经有挂钟、台历、台钟和公告板，后沿又放了一只 LED 钟、一张便签、一个专注面板；画里的书本上叠着歪斜的字。
3. **网页控件没有去干净**：深色胶囊按钮、底部深色卡片、区域铜牌、「家具与无障碍入口」链接；铜牌上的字太小。
4. **房间悬在黑底上**，和木纹后沿没有关系；抽屉拉出来压住底栏。
5. **面板里什么材质都有**：专注面板同时有纸、LED、标签页、铜牌和线圈本。
6. **手机端**两行铜牌加一大块唱机，挤在一起。

结论：问题不在细节，在路线。等距房间需要摆放、遮挡、透视对齐，实物加得越多越乱。DEsk 好看是因为只有两种视角，每个视角是一张渲染好的图，交互件按固定坐标放在图上。作者确认方向：「不要使用我们这种 3D 实物化」「完全按照他们的风格来打造一个属于我们的软件」。

| R2 唱机 | 套在 `view-console` 上：荧光屏、两只表、音量旋钮、拨杆、推子、按钮、钥匙对应播放器的每个功能 |

## 移除

- 等距首页：`CabinHome`、房间画布、三个角落（素材、镜头、导航）、读数、家具小物、旧 LED 台钟、旧抽屉（选择小屋相册、布置托盘）、顶栏与热点、正在播放条，以及只有家具能打开的挂历、植物、茶歇、休息角面板。
- 场景选择（八个房间）：设置和新手引导里只剩选伙伴。保存的 `look` 仍决定歌词样式，不迁移数据。
- 原版唱片架首页与「改用原版」的所有切换；旧的首页选择会被忽略。
- 素材：`public/room-scenes/` 下的家具图集、角落画面、房间外壳（以 `git rm` 记录为准）。

## 边界（未实测）

- Android、Windows、macOS 真机上的观感与声音未看过；Android 原生部分未编译。
- DEsk 的底图只有 1440×900 一种比例：超宽屏两侧多出木纹，竖屏的抬头视角靠左右平移。
- 唱机上的进度依赖音源上报的时长；「仅展示」模式下唱臂停在外圈。
- 纸张折角的「掀起」依赖 `@property`（Chromium、Electron、Safari 16.4+）；不支持的浏览器里直接跳到掀起后的大小。
- 手写字体用系统楷体；没有安装的机器回退成无衬线体。
- Electron 界面测试需要联网和系统钥匙串，部分在无外网的沙箱里不能运行，以 CI 为准。
