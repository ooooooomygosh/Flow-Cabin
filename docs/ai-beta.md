# AI（Beta）与小屋来信

Off by default. 设置 › AI（Beta） takes a base URL, API key and model for any OpenAI-compatible `chat/completions` endpoint (DeepSeek, OpenAI, a local Ollama `…/v1`, …).

- **Key storage.** Saving a key binds it to the exact normalized endpoint. Desktop: the page sends the key to the shell (`album-desktop://action/ai-key`), which stores the credential in `userData/ai-key.bin` encrypted with Electron `safeStorage`; without OS encryption (including Linux `basic_text`) it is kept in memory for the session only. The page only receives `{ stored, secure, endpoint, revision }`. Web: a versioned, endpoint-bound credential lives in `localStorage['flow-cabin-ai-key-v1']`, this browser only. Old unbound credentials must be saved again. Backups exclude credentials and AI connection settings. The key is never logged, and error texts are redacted.
- **Requests.** Desktop: the page CSP is `connect-src 'self'`, so `/ai-chat` is relayed by `desktop/ai.cjs` in main (`net.fetch`, 30 s timeout) and answered with the `cabin:ai-result` event. Web: `fetch` from the page — **the endpoint must allow CORS** (many hosted APIs don't; use the desktop app then).
- **Endpoint changes.** HTTPS is required except for loopback HTTP. URL credentials, query strings, fragments and redirects are refused. An existing key cannot be sent to a changed endpoint. Changing or clearing a key invalidates pending responses; changes to AI settings invalidate pending letters.
- **测试连接** sends one tiny chat/completions request (`max_tokens: 8`) and shows success or a plain-language error (401/404/429/5xx, timeout, network/CORS, non-OpenAI response).
- **小屋来信.** Daily (about yesterday) or weekly (about last Monday–Sunday), tone 温柔 / 俏皮 / 平静鼓励. One saved letter per period (`flow-cabin-letters-v1`); history is retained without a count cap. Focus time and verified playback time are separate. Weather describes the window at the time of writing. Task text and raw history are excluded. Notes are excluded by default; the optional permission includes at most a 300-character excerpt. Without AI, or on an empty/failed AI response, a local template letter is saved with the same evidence and read state. A period without activity does not create an automatic unread letter.
- **双向信箱.** 小屋日记 › 信箱 shows incoming letters and outbound threads, with direction filters and pagination. The composer saves locally on every input, retains the decision not to attach context, and supports up to 2,880 characters without per-paragraph truncation. Sending saves the original before contacting the configured service. Notes require a separate per-send checkbox. The old draft is removed only after the reply is saved; a newer draft written elsewhere is preserved. Interrupted requests can be completed with a local reply without transmitting the letter again. Changed AI settings invalidate late AI replies.
- **Backup.** Backup v3 retains incoming/outgoing direction, drafts, sent state, reply threads, evidence and read receipts. Legacy letters migrate to incoming letters. Credentials and AI connection settings remain excluded.
- **Tests.** `src/ai/ai.test.mjs`, `desktop/test/ai-relay.test.cjs`, browser: `npm run test:ai` (`scripts/ai-beta-regression.mjs`, mocked endpoint).
