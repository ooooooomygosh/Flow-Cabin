# AI（Beta）与小屋来信

Off by default. 设置 › AI（Beta） takes a base URL, API key and model for any OpenAI-compatible `chat/completions` endpoint (DeepSeek, OpenAI, a local Ollama `…/v1`, …).

- **Key storage.** Desktop: the page sends the key once to the shell (`album-desktop://action/ai-key`), which stores it in `userData/ai-key.bin` encrypted with Electron `safeStorage`; without OS encryption it is kept in memory for the session only. The page never gets it back (it only sees `window.cabinAiKey = { stored, secure }`). Web: `localStorage['flow-cabin-ai-key-v1']`, this browser only. The key is never logged, and error texts are redacted.
- **Requests.** Desktop: the page CSP is `connect-src 'self'`, so `/ai-chat` is relayed by `desktop/ai.cjs` in main (`net.fetch`, 30 s timeout) and answered with the `cabin:ai-result` event. Web: `fetch` from the page — **the endpoint must allow CORS** (many hosted APIs don't; use the desktop app then).
- **测试连接** sends one tiny chat/completions request (`max_tokens: 8`) and shows success or a plain-language error (401/404/429/5xx, timeout, network/CORS, non-OpenAI response).
- **小屋来信.** Daily (about yesterday) or weekly (about last Monday–Sunday), tone 温柔 / 俏皮 / 平静鼓励. One letter per period (`flow-cabin-letters-v1`, last 60); a failed try waits an hour (`flow-cabin-letter-try-v1`). The prompt is built from summary stats only (`letterSummary` in `src/ai/ai-model.mjs`): focus minutes, sessions, completed sessions, active days, top 3 albums, and cat tier/mood/feeds from `readCatMood` (`flow-cabin-cat-mood-v1`). No task text, notes, timestamps or raw history. When AI is off, fails or times out, the journal keeps showing the template letter (`cabinLetter`).
- **Tests.** `src/ai/ai.test.mjs`, `desktop/test/ai-relay.test.cjs`, browser: `npm run test:ai` (`scripts/ai-beta-regression.mjs`, mocked endpoint).
