# 心流小屋 · 产品计划

本轮目标：围绕「选一个喜欢的房间 → 找一位伙伴 → 放唱片 → 安静专注」形成完整体验，保留唱片收藏的产品辨识度。参考沉浸空间与陪伴体验，不复制 Steam 游戏角色或美术。

这是一份开发与验收计划，不是发布声明。逐项实现及证据见 [功能矩阵](audit/feature-matrix.md)，审查基线与音乐边界见 [产品审查](audit/2026-10-product-review.md)。

## 已有基础，继续保留

- 本机收藏、旧版本迁移、十二格唱片架、唱片卡片、曲目与笔记、黑胶外观、唱片盒、筛选及专辑墙导出
- iTunes／MusicBrainz／QQ 曲库检索，本地文件、系统正在播放、QQ／网易云和 Music Assistant 音源入口
- 番茄钟、待办、统计、奖励、沉浸模式、合成环境音和离线 Lofi
- Electron 桌宠、动态桌面、托盘及备份；macOS／Windows 实现仍需各平台真实验收

## 本轮实现范围

| 产品需求 | 实现 | 放行标准 |
|---|---|---|
| 更多安静空间 | pixel 像素、warm 琥珀、night-study 月夜书桌、forest 林间、seaside 海边、starlight 星夜 | 六场景均能加载、十二格封面对齐、切换及重载保持选择 |
| 有辨识度的伙伴 | cat 奶糖、chick 蛋挞、bunny 棉花、bear 可可、fox 枫糖 | 独立轮廓与动作、配饰、点击反馈和静态模式；原有猫兼容 |
| 统一布置入口 | 「布置小屋」预览并保存场景／伙伴 | 键盘可操作、保存失败可见；不重置音乐和专注 |
| 随手记录 | notes 内置纯文本便签及备份 | 长度限制、旧备份兼容、存储失败提示、清空确认 |
| 连续专注可靠性 | 自由专注、任务清理、时长编辑、睡眠恢复、DST 统计 | 可控时间测试不重复奖励，跨时区边界不误算 |
| 音乐与桌面可信状态 | 请求取消、退出登录、凭证隔离、本地路径和快照校验 | 不把失败当成功；不复用旧服务器凭证或失效播放请求 |

内置扩展范围只有专注／待办／统计／声音／随手记注册表及场景、伙伴目录。任意第三方插件加载、权限沙箱、市场安装均未实现。

## 验证阶段与交付门槛

1. **实现与确定性回归**：Node 模型、临时文件及模拟服务测试，前端构建；默认测试已包含 16 项音频生命周期回归。以最终提交的实际日志为准，不在计划中固定易过期的通过数量
2. **隔离交互预览**：模拟收藏与媒体数据，明确显示预览标识；禁止真实账号、外部请求和原生操作。Vercel 隔离夹具预览已用于云浏览器验证，不替换生产部署
3. **浏览器／模拟桥回归**：操作、重载、备份、键盘、音频夹具和多窗口页面渲染。云浏览器人工检查已覆盖五场景／伙伴、收藏操作、笔记、重载与紧凑布局；V3 页面自测 22/22 通过，错误列表为空，含实际 WAV 播放、PNG 导出和一分钟专注。这段 V3 云端记录中的独立 Playwright 当时启动受阻；10 月 11 日已在 Mac 的隔离工作区完成真实 headless Chromium 回归，最新证据见 [本轮验收](audit/integration-2026-10-11.md)，历史见 [执行记录](audit/browser-validation.md)
4. **真实系统与账号验收（NOT RUN）**：macOS Intel／Apple Silicon、Windows 打包安装，桌宠拖动与穿透、壁纸挂载与退出、权限拒绝恢复、本地文件、真实平台登录与完整歌曲、重启恢复
5. **发行审查**：处理桌面依赖的剩余安全公告，明确根许可证与 GPL 组合代码的源码／分发义务，再决定签名、公证、版本和发布目标。没有授权时不发布或重新许可

V3 之后新增的伙伴绘制节奏优化已有单元／构建验证，但未包含在 V3 快照内，须在新版预览继续验证；不能将 V3 结果推广为最终代码已全量验收。

PR CI 的工作流配置只是验证入口。浏览器模拟通过不替代真实平台验收，旧提交的通过结果也不能替代最终提交。

## 后续优先级

- **P0 发行阻断**：真实设备及账号验收、安全公告评估、许可证澄清，确认安装与数据恢复路径
- **P1 体验打磨**：基于实际截图检视布局与可读性，完成键盘、减少动态效果、错误恢复及长时间使用验证
- **P2 独立提案**：账号同步、官方 Spotify／Apple Music 接入、用户素材导入、更多剧情与场景。先确认权限、存储、安全和维护成本，再进入开发

官方音乐 SDK 不是现有“控制系统播放器”的同义词。[Spotify SDK](https://developer.spotify.com/documentation/web-playback-sdk/) 与 [Apple MusicKit](https://developer.apple.com/musickit/) 的开发者配置、授权、订阅及平台限制必须另行评估；本轮不将它们标注为已完成。
