# 心流小屋 · 产品计划

当前基线：2026-10-19，`main` 为 `v1.19.0` 的发布候选，包版本为 `1.19.0`；发布流水线完成前 GitHub 最新公开版本仍是 `1.18.0`。#61、#66、#67、#68 已合并，其中 #61 已完成。

产品的核心循环不是把番茄钟、词书和播放器堆在一起，而是让人愿意每天回到同一个地方：选一间熟悉的屋子，放一张唱片，和奶糖待一会儿，完成一段专注，再留下一点以后愿意翻看的记录。听歌、陪伴、专注和回忆必须互相提供情绪价值，而不是各做一套互不相干的工具。

## 产品方向

- **低摩擦回访**：打开就能继续上次的唱片、房间和专注状态；新增功能不打断已有任务。
- **有分寸的陪伴**：伙伴通过动作、装扮和少量即时反馈回应人，但不用频繁弹窗争夺注意力。
- **可感知的仪式**：泡茶、浇花、开窗、连星图这类小互动让房间像“住过”，但不把每一次点击变成打卡负担。
- **可沉淀的记忆**：手记、来信、播放与专注记录形成可检索、可回顾的个人空间；删除和备份规则必须让人能够信任。
- **轻量成长**：学习、纪念物和装扮提供持续推进的理由，不把未完成变成羞耻或惩罚。

## 永久删除与备份

- 手记和**整组往来信**只能从回收站永久删除，并需要第二次确认；普通移除仍可恢复。
- 永久删除后只保留 `{ id, purgedAt }` 标记。正文、标签、历史与回信正文不再保存；旧窗口、旧草稿或迟到回信不能复活内容。
- 备份格式为 v4：保留删除标记，但不包含已删除正文。没有删除记录的新 profile 仍可导入外部旧备份；导入旧备份不能推断或恢复未知的永久删除。
- 纪念物独立保留，不会因为清理手记、信件或信箱回收站而一并消失。
- 回收站、手记、信箱、播放日志与纪念物各自承担不同语义，不应把“可恢复移除”和“永久删除”写成同一件事。

## 学习内容

- 12 个原创日常主题覆盖居家、饮食、购物、出行、协作、学习、数字设备、身体休息、关系、户外、计划和社区，每个主题 20 词。
- 原 `book-daily`、`book-work`、`book-music` 三本书各 6 词，保留原有目录顺序、文本与已学记忆，总计 15 本、258 词。
- 新卡背面包含词性与中文释义、原创英文例句和中文译意。每日新词额度跨主题共享，词条按需发卡，不预生成本套全部卡片。
- 这套内容是项目原创学习材料，**不是完整考试词库、官方分级或 CEFR 认证**，也不宣称获得第三方词典、教材、考试机构或分级体系授权。详见[学习内容说明](study-original-wordbooks.md)。

## 验证与发布边界

1. **确定性回归与隔离页面**：当前分支已有模型、构建和隔离浏览器专项覆盖；是否可合并应以最终 CI 与完整 QA 日志为准，不在公开文档里固定易过期的通过数量。
2. **原生输入与长期运行**：macOS 当前处于锁屏状态，因此真实键鼠、原生焦点和全天原生验收没有完成。浏览器 `document.hasFocus()`、模拟桥或截图都不能替代系统焦点、权限和物理设备证据。
3. **平台与账号**：Windows、Intel Mac、真实 QQ / 网易云 / Apple Music 账号、全局输入权限和原生壁纸挂载仍未完成实机验收。
4. **安装与升级**：v1.17.0 到当前版本的同安装路径、同 profile 替换、重启和逐域数据比较尚未执行。旧包存在且校验通过，不等于安装器升级验收通过。
5. **发行**：当前没有完成 Apple Developer 签名、公证、Windows 可信发布者签名或自动更新器端到端验收；本地打包成功也不等于可正式发布。

真实账号、系统权限和不在当前机器上的平台必须在对应环境取得证据后再更新本页。模拟服务、编译通过、生成安装包和隔离浏览器页面都不能替代真实验收。

## 后续优先级

- **P0 发布阻断**：完成 v1.17.0 → 当前版本安装器升级；补 macOS 真实输入 / 原生焦点 / 全天运行，以及 Windows、Intel Mac、全局输入权限和原生壁纸挂载验收；完成正式签名、公证与更新源验证。
- **P0 法务与依赖**：明确根项目许可证和 GPL-3.0-only Simple Music 组合分发义务；每次锁文件变化后重跑生产依赖审计，并在最终安装包中验证本地加密适配层。
- **P1 体验打磨**：基于真实截图、真实账号和长时间使用检查布局、错误恢复、减少动态效果与数据恢复；不新增与核心循环无关的功能。
- **P2 独立提案**：账号同步、官方 Spotify / Apple Music SDK、用户素材导入和更多剧情场景。先确认权限、授权、存储、安全与维护成本，再进入开发。

官方音乐 SDK 不是“控制系统播放器”的同义词。[Spotify SDK](https://developer.spotify.com/documentation/web-playback-sdk/) 与 [Apple MusicKit](https://developer.apple.com/musickit/) 的开发者配置、授权、订阅和平台限制必须另行评估；当前不将它们标注为已完成。
