# 月夜书桌、动态桌面、全屏与自动选源验收

2026-10-09，在用户的 Windows 本机、Electron 44.6.0 上，从 main `dc25f8fc0ca96e6a50cc0a780e146228911ab5b2` 验证。测试使用独立用户目录与专辑夹具，不修改真实收藏或音源账户。

## 使用与行为

- 「布置小屋 → 月夜书桌」使用用户原图，九格木架每次展示三行，滚轮、方向键及首尾跳转按三列计算。新收藏默认使用月夜书桌，已有场景偏好继续保留；入门指南兼容六种场景。
- 手部使用透明 16 姿态图集：书写、抬筆、拇指转笔、接笔、下笔。没有缩放或扭曲背景矩形。减少动态效果时保持静止，页面隐藏时停止动画调度。素材及生成规格见[美术规范里的月夜书桌一节](art-direction.md#moonlit-study-月夜书桌-night-study)。
- 封面降低亮度及饱和度，叠加朝向远离左侧台灯的渐变、格子顶部与右侧遮挡、投影；右列及下排更暗，鼠标悬停保留照明。
- 动态桌面和软件小屋使用同一场景及只读收藏快照。等待独立 session 的协议检查完成后注册资源，等待真实场景图片绘制，显式启动 Chromium compositor，再清除自有窗口边框并校准显示器边界。仅修改软件自己的窗口。
- 全屏按钮 / F11 使用原生窗口全屏，覆盖任务栏。隐藏顶部栏、工具栏、唱机、底部资料、猫咪文字、筛选及弹窗；Esc / F11 恢复。页面重载后保留全屏状态。软件设置打开时进入全屏会回到场景。
- 选中音乐音源后自动匹配歌名、歌手及版本，优先原始曲目 ID 和同专辑，逐个跳过不可解析或播放失败的候选。QQ / 网易云之间允许后备；「自动匹配可播放音源」先试 QQ，再试网易云。本地文件与 Music Assistant 保持所选服务。无法匹配时仍可手动选择，不自动替换为另一位歌手或现场版。下拉切歌重新匹配，旧请求取消后不能播放上一首。

## 本机证据

Computer Use 实际操作确认 F11 进入和 Esc 退出：全屏窗口边界与显示器边界一致，为 2560×1440；任务栏、软件顶栏和控制区消失。

原生桌面 probe：`behindIcons=true`、`visible=true`、`hasFrame=false`、`coversMonitor=true`，窗口和客户区均为 2560×1440。完整 Windows 桌面合成截图可见真实场景和桌面图标，没有纯色覆盖层。

新增测试直接读取 Windows 桌面父窗口合成，在任何浏览器截图刺激绘制之前捕获唱片格子，首次应用、关闭主窗口后及重新应用时与场景参考区域一致。关闭主窗口后，两次桌面手部合成捕获有 1797 个像素变化，确认背景动画仍在实际桌面上前进。

## 验证边界

音乐平台接口和 Music Assistant 使用模拟服务，HTMLAudioElement 对测试 WAV 的解码、时间推进、暂停、切换是真实行为；未使用真实 QQ / 网易云账户验证会员曲目、平台实时可用性或扬声器输出。

本机缺少 `Windows.winmd`，无法构建 NowPlaying；系统播放器回归使用模拟状态与控制，不声称真实系统媒体读取已通过。文件符号链接安全测试仅在 Windows 返回 EPERM 时跳过；具有权限的 Windows 和非 Windows 环境仍执行原断言。未验证 macOS、第二块显示器或安装包分发。构建产物、测试用户目录、桌面私人图标截图和凭据不提交。
