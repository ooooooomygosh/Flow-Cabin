# 日常实用英语：原创学习内容 v1

心流小屋内置 **15 本、258 词**学习目录：12 个原创日常主题各 20 词，共 240 词；另保留 `book-daily`、`book-work`、`book-music` 三本兼容入门书，各 6 词，共 18 词。

这是一套项目原创的日常英语学习材料，**不是完整考试词库、官方分级或 CEFR 认证**。它不宣称覆盖某项考试，也不宣称获得第三方词典、教材、考试机构或分级体系的授权。

## 学习设计

- 每个新词学习一个明确的常用义项。背面依次显示词性与中文释义、原创英文例句和中文译意。
- 译意表达例句在当前场景里的意思，不追求逐词对应。多义词只解释该句使用的含义，例如 `change` 的找零、`patient` 的有耐心和 `stage` 的舞台。
- 词条目录不是预生成卡片。预览或打开词书不会一次性创建 258 张卡；只有当前学习请求才会创建下一张尚未存在的卡片。
- 每日新词额度跨主题共享，切换主题不会重置额度、记忆或学习日志。已有卡片按既有 NFKC、大小写归一化规则去重。
- 内容与记忆分开保存。备份只包含已经创建的卡片、卡组、记忆、额度和日志；尚未学习的词条仍随应用目录提供。

## 内容来源与兼容

新增文本位于 `src/study/books/practical-english.mjs`，由 `src/study/word-books.mjs` 接入现有目录。`PRACTICAL_SERIES` 提供系列名称、版本、主题数与词数。每个主题沿用稳定的 `id/name/description/source/words` 结构。

新卡卡组和实际生成的卡片会保存来源说明，例如：

```text
本项目原创学习材料，不是完整考试词库/官方分级 · 日常实用英语 v1 · 居家收纳（home）
```

已有但没有来源字段的旧卡不会被追溯改写。恢复到支持当前目录的版本后，可以从尚未创建的词继续学习；较旧版本可以保留已备份的卡片和来源，但没有新目录时不能自动补出尚未学习的词条。

## 生产与发布边界

- `src/study/books/practical-english.test.mjs` 覆盖主题和词数、唯一性、双语字段、旧书兼容、按需发卡、跨主题额度和备份往返；实际是否可合并以最终测试日志与 CI 为准。
- 独立浏览器专项可以验证预览、评分、备份导出和恢复，但不等于已打包 Electron、真实用户目录或原生平台验收。
- 这些文本没有经过官方考纲、词典出版方或语言认证机构审定。界面和文档不应把它表述为“考试必备”“官方分级”“完整词库”或第三方授权内容。
- 词条更正应尽量保留稳定主题 ID 和目标词，避免已学卡片重复生成；修正目录不会自动覆盖用户已经保存或编辑的卡片。

相关边界见[使用限制](limitations.md)与[产品计划](product-plan.md)。
