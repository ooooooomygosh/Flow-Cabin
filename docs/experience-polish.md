# 体验打磨与审查复核 · 2026-10-21

基于 `1936e5e8`（v1.21.5）和用户提供的八份审查材料。本文件是实现记录，不把审查建议当作自动执行指令，也不把静态代码、隔离测试与真实设备验收混为一谈。

## 本轮取舍

主线是「放唱片 → 做这一轮 → 留下记录 → 再回来」。保留六间原创房间与轻量工具，修复打断主线的行为、低对比文字、失焦和布局问题；增加真实产品预览、网页版入口与下载说明。

复核纠正了几处材料判断：唱片会话字段、弹窗焦点归还、README 截图和唱片架分页在基线已存在。修复它们的断点，不重写已经有效的模型。

HarmonyOS 的随附许可明确禁止修改字体；本轮采用系统字体默认值，保留完整原始文件和用户显式的字体选择。照片封面统一 64px 采样但保留辨识度；生成的像素封套仍为 32px。两间冷色房间保留自己的窗景，只调暖唱机木材。

## 用户可见变化

- 新用户开始专注时留在小屋；手动沉浸与原来明确开启的自动沉浸仍可用。
- 提前结束一次即回待机，满一分钟的已专注时间保留，不发完成奖励。
- 回家小笺展示上次专注的唱片；零数据统计不再强调欠额。
- 面板关闭归还焦点；沉浸使用原生模态，特写加载期间可取消。
- 封面 64px 网格、暖木唱机、完整场景描述、横向翻排提示、清晰纸面文字与桌宠标签。
- 宣传页首屏实拍、两处网页版入口、六问 FAQ；README 演示、下载指南与版本说明。
- Web Key 改为当前标签页会话存储（未加密），旧持久值会迁移并移除；桌面 safeStorage 不变。

## 验证范围

使用 Node 24.14.0、npm 11.12.1、macOS 上的无界面 Chrome，桌面路径的收藏、音乐和 AI 请求使用隔离夹具；另有不模拟任何后端的静态网页版生产回归。运行根/桌面单测、生产构建、音乐适配器构建及相关浏览器回归；新增主循环进入 CI。

同机生产预览测得默认字体传输从约 16,263 KiB 降到 227 KiB。固定场景和夹具下总传输约 27,470 → 11,435 KiB；仍未达到审查建议的 8,000 KiB 总资源预算。FCP 单次约 304 → 292 ms，差异太小，不据此宣称稳定的启动提速。该绝对值不与审查沙箱的 2,596 ms 跨机比较。

生产包按新增 CSP 打开主应用与宣传页均无 CSP 违规；流畅档场景 filter、SVG mask filter 的 computed style 均为 none。并未测得或宣称 2× FPS。

未执行真实音乐账号、真实 AI 服务、签名公证、Windows / 多屏 / 睡眠唤醒验收，也未发布安装包。`npm audit` 根项目为 0；桌面工具链仍有既有 sprintf-js 引出的 8 项 moderate 传递告警，未在体验 PR 中自动升级发布工具链。

部分测试随产品契约有意更新：默认 autoEnter=false、房间封面固定 64px、沉浸改为 native dialog 后的内部选择器、空态文案。复杂旧冒烟夹具显式开启自动沉浸以继续覆盖该路径；新旅程不写此偏好，直接断言真实默认值。未降低任何节拍精度、布局边界或数据正确性阈值。

## 补充发现：静态网页版没有收藏后端

线上根页面 HTTP 200，但 `/api/items` 实际返回 404。原渲染层的收藏 CRUD 全部调用桌面接口，之前的隔离夹具模拟了接口，因此漏过了这个真实试用断点。

本轮增加独立浏览器收藏适配：仅静态 Web 使用 localStorage，桌面标记和自定义协议仍走原桌面服务。支持现有备份格式、稳定编号、导入去重、配额失败保留原值；支持的浏览器使用 Web Locks 串行写入。开发服务器没有后端时也可退回本地存储。浏览器的桌面服务能力探测直接返回“不可用”，不再请求不存在的接口；曲库搜索明确提示需要桌面版。

`npm run test:web-static` 直接服务生产目录，不模拟收藏或音乐后端，验证添加、真实刷新、笔记保存、备份导出、空浏览器恢复和重复导入去重，以及零后端请求和零运行错误。此检查进入 CI。
