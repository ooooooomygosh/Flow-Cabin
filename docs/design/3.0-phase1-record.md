## 验证

- `npm run qa` 全部通过：前端单元 753、桌面单元 433、移动 8；构建；21 个浏览器回归。
- 合并后又单独重跑：interface、home、home-interactions、lyrics、focus-ui 通过。
- 浏览器实际走查：新用户首页、唱片架空状态、专注面板、唱片日记、手机宽度。

## 仍未通过 / 未验证（早于 3.0，或需要真机）

- `test:layout`（Electron）：1440×900、缩放 1.5 时「唱机特写入口」检查失败。
- 部分桌面 Electron 夹具（room、backup、pet、atmosphere、improvements、music、cat-focus）在 3.0 之前的提交上同样失败；需先 `npm --prefix desktop run build:web`。
