# 心流小屋 3.0 · 设计文档

> 基线：`main` @ `8b8948c`（v2.2.0）。日期：2026-10-26。
> 配套：[竞品与设计原则调研](competitor-research.md)。
> 本文是 3.0 的产品宪法：之后任何新功能，先回答“它让下面这个循环更好了吗？”，答不上来就不做。

---

## 0. 一句话

> **放一张你自己的唱片，和奶糖一起做完这一段。每一段专注，都会变成架上的一张唱片。**

英文：*Put on a record. Do one thing. Keep the song.*

---

## 1. 诊断：为什么现在是“四不像”

v2.2 在两周里合入了约 600 个提交，每个点子单独看都不错，但它们没有共同的主轴：

| 现象 | 证据 | 后果 |
|---|---|---|
| **两套首页并存** | 原版唱片架（像素，音乐是主角）与生活小屋（手绘 2.5D，家具是主角）同时维护；默认已切到生活小屋 | 新首页里音乐被挤到左下角一个小条「今天想听什么？」，产品的护城河反而退居二线 |
| **一级入口过多** | 顶栏：专辑墙 / 唱片库 / 专注 / 随手记 / 布置 / ⚙ / 全屏；齿轮里又有 8 项「小屋日常」；三个角落 + 全屋 | 用户不知道“这个软件是干什么的”，每次打开都要先做选择 |
| **专注面板塞了 6 个标签** | 番茄钟 / 待办 / 统计 / 学习 / 声音 / 随手记，外加智能唱片机推广条、画面切换、四档预设 | 最常用的“开始专注”反而不突出 |
| **三套并列的“激励系统”** | 小鱼干（货币）+ 心情值 + 纪念物 + 连续天数 + 来信 + 明信片 | 动机被稀释，也违背“温馨”——温馨来自安全与富足，而不是记账 |
| **记录分散在四处** | 随手记、手记、信箱、小屋日记统计、纪念物 | 想回看“我那天做了什么、听了什么”时没有一个地方能回答 |
| **美术语言不统一** | 手绘写实近景 + 等距全屋 + 像素字体 UI + 像素猫/手绘猫 + 圆角暗色面板 + 9-slice 像素边框 | 每块都好看，放在一起就不“高级” |
| **空状态劝退** | 唱片库空的时候先展示 5 个筛选下拉框 | 第一次打开的人看到的是表单，而不是音乐 |

**根因**：没有写下来的核心循环，于是“家具”“桌宠”“日记”轮流成为主角。3.0 要做的不是再加东西，而是**选定主角，并让其余一切为它服务**。

## 2. 定位与场景

### 2.1 我们是谁、不是谁

- **是**：一个**带陪伴的音乐专注播放器**。真实曲库（QQ / 网易云 / 本地 / Apple Music）+ 逐字与桌面歌词 + 唱片收藏 + 不愧疚的专注陪伴。
- **不是**：lofi 电台（Spirit City、Chill Pulse 只有内置 lofi）；不是“科学专注音乐”（Brain.fm、Endel）；不是装修游戏；不是学习 App；不是日记 App。

调研结论：Steam 上的 cozy 小屋都没有真实曲库，音乐 App 都没有专注与陪伴。**我们站在交叉点上，这个交叉点就是护城河。**

### 2.2 三个典型时刻

| 场景 | 人在做什么 | 小屋的样子 | 最重要的体验 |
|---|---|---|---|
| **电脑前办公 / 学习** | 写代码、写论文、刷题，小屋在副屏、角落或后台 | 迷你唱机 / 桌面歌词 / 桌面奶糖 / 菜单栏 | 一键开始专注、一键红心、切歌不切窗口、占用低 |
| **书本学习** | 笔记本立在书旁，人看书 | 全屏沉浸：唱片计时 + 房间 + 慢歌词 | 远看也能读的时间、温暖的画面、零打扰 |
| **放松听歌** | 下班、睡前、发呆 | 小屋窗口：听歌角、歌词、唱片架 | 好看的唱片、好听的过渡、好读的歌词 |

## 3. 核心循环

```
   ┌─────────────── 选一张唱片（听）───────────────┐
   │   继续上次 / 唱片架 / 我喜欢 / 一句话让小屋挑      │
   ▼                                              │
 开始这一段（专注）── 写一句“这段做什么”（可跳过）       │
   │   奶糖在旁边安静地陪着（陪伴，不索取）             │
   ▼                                              │
 这一段结束 ── 唱片“压制”完成：封面 + 这段做了什么      │
   │           + 可选一句话 + 当时的天气与房间          │
   ▼                                              │
 收进唱片日记（留下）── 房间随累计时光慢慢变暖 ──────────┘
```

- **听**是入口，**专注**是动作，**唱片日记**是回报，**奶糖与房间**是情绪。
- 四件事合成**一个动作**：你只需要“放唱片、开始”，其余都是自动发生的。
- 被打断的专注**不留痕**：没有失败，只是“这张没录完，放回去了”。

## 4. 三根支柱 + 一个灵魂

| | 支柱 | 职责 | 体验标准（必须做到） |
|---|---|---|---|
| 1 | **听 Listen** | 一切的入口与差异化 | 打开 3 秒内能“接着听”；红心一键可达；歌词一键可达；切歌无缝；空库也不冷场 |
| 2 | **专注 Focus** | 把听歌变成做成一件事 | 一次点击开始；结束有仪式感；暂停/跳过/超时都不惩罚 |
| 3 | **唱片日记 Keep** | 长期动力：回看“我和哪些歌一起做完了哪些事” | 零输入也有内容；一周一张合集；一年一面唱片墙 |
| ♥ | **奶糖与小屋（灵魂）** | 不是系统，是**表达层**：把上面三件事的状态变成表情、姿势、光线 | 有自己的生活节奏；永远不索取、不生病、不离开 |

**取舍规则**：家具 = 舞台，不是功能；桌宠 = 灵魂的延伸，不是第二个产品；日记 = 专注的副产品，不是写作 App。

## 5. 信息架构

### 5.1 一级入口：只有三个

顶栏只保留：**唱片架 · 专注 · 日记**，以及右侧的 ⚙ 设置。

| 原入口 | 3.0 去向 |
|---|---|
| 专辑墙 | 并入「唱片架」，作为其中一个视图（网格 / 墙） |
| 唱片库 | 改名「唱片架」，成为听歌的主页面 |
| 专注 | 保留 |
| 随手记 | 并入「专注」（这一段的便签）和「日记」（回看） |
| 布置 | 移到房间名下拉菜单「布置小屋」（二级） |
| 齿轮「小屋日常」8 项 | 只留：选择小屋、布置小屋、备份与恢复、全部设置；其余进实验室 |
| 原版唱片架首页 | 不再作为“另一个首页”；它的精华（唱片墙做主角）成为「唱片架」页面。设置里保留“经典首页”开关一个版本，供老用户过渡 |

### 5.2 三种形态（同一个状态，三种大小）

1. **小屋**（窗口打开）：房间是背景，底部是常驻的**正在播放条**，右上是专注状态胶囊。
2. **沉浸**（专注时 / 看书时）：唱片计时 + 慢歌词 + 房间虚化。
3. **桌面边缘**（后台工作时）：迷你唱机、桌面歌词、桌面奶糖、菜单栏 / 托盘。

三种形态共用同一个播放器、同一个计时器，切换时不打断任何东西（现有实现已保证，继续守住）。

### 5.3 实验室（隐藏，不删除）

与核心循环关联弱、或需要额外配置的功能，进入「设置 › 实验室」，默认关闭；**已经用过的人升级后保持开启**（按本机数据判断，见 `src/product/features.mjs`）：

| 功能 | 理由 |
|---|---|
| 词书学习（FSRS） | 与音乐/专注关联最弱，调研中最先建议砍掉；保留给已在用的人 |
| 小屋来信 / 信箱 | 情绪价值并入日记的“结束一句话”与周合集 |
| 智能唱片机 | 需要配置 AI；开启后在唱片架里显示“让小屋挑一张” |
| 设备联动 | 高级能力，少数人需要 |
| 场景配方与睡前 | 睡前淡出将来作为播放器的“定时停止” |
| 小屋明信片 | 由日记的“分享这一周”替代 |

**纪律**：只隐藏入口；数据、备份、同步格式全部不变。

### 5.4 设置：9 个分区 → 6 个

| 3.0 分区 | 包含（来自旧分区） |
|---|---|
| 音乐 | 音源与账号、音质、过渡、歌词 |
| 专注 | 专注工具、提醒、专注画面 |
| 小屋与奶糖 | 房间与桌宠、键鼠陪伴、天气位置 |
| 桌面 | 显示与桌面、快捷键、开机启动 |
| 数据 | 数据与备份 |
| 实验室 | AI（Beta）、同步与设备、上表中的功能开关；「关于」放在底部 |

## 6. 关键体验规格

### 6.1 首页（小屋）

- 默认进入**全屋视图**（等距小屋很美，保留），但画面上**只标注三个热点**：唱机（→唱片架/听歌角）、书桌（→专注）、窝与日记本（→日记）。其余家具是布景，悬停不弹标签。
- 底部常驻**正在播放条**（见 6.2），替换现在的「今天想听什么？」小条。
- 第一次打开：引导 3 步不变；结束后直接给出**一张可以立刻播放的唱片**（本地 / 网页版用内置示例），让人 60 秒内听到声音。
- 回访问候：按时间段一句话（“早上好，先放点轻的？”），点一下就继续上次的唱片。**永远不出现“你已经 X 天没来了”。**

### 6.2 听歌

**正在播放条（全局常驻，首页底部）**
- 左：封面（点击 → 听歌角 / 唱机特写）、歌名、歌手，下方一行**当前歌词**（无歌词时显示专辑名）。
- 中：上一首 / 播放暂停 / 下一首，细进度条可拖。
- 右：♥ 红心、歌词（→沉浸歌词）、待播队列、音量；以及一个「开始这一段」按钮（→专注）。
- 空状态：「放一张唱片」按钮 + 最近播放的 3 张封面。

**唱片架（一级页面）**
- 顶部三个视图：**唱片**（专辑与歌单，封面网格是主角）/ **我喜欢**（红心歌曲列表）/ **最近播放**。
- 筛选、排序、唱片盒收进一个「筛选」按钮；唱片少于 12 张时不显示筛选。
- 专辑墙作为“唱片”视图里的一个展示模式（网格 ↔ 墙）。
- 空架子：一句温柔的话 + 两个按钮（搜索添加 / 导入本地音乐），不展示任何表单。

**我喜欢**
- 红心是一级动作：正在播放条、迷你唱机、桌面歌词条、快捷键都能一键红心（现有 `likes.mjs` 已有数据，3.0 第一次给它一个家）。
- 列表：歌名、歌手、来自哪张唱片、加入时间；点击即播放，可“全部播放 / 随机播放”。
- 后续（Phase 2）：同步回来源平台；作为“让小屋挑一张”的种子。

**歌词**（v2.2 已经很强，3.0 只做收敛）
- 正在播放条上的单行歌词是新的高频触点。
- 专注时桌面歌词默认淡到一行（可在设置关）。

**播放底线（守住，不退化）**：继续上次、无缝/淡入过渡、不可播放标灰说明原因、系统媒体键。

### 6.3 专注

- **一次点击开始**：正在播放条的「开始这一段」、书桌热点、菜单栏、全局快捷键。默认时长用上次的设置。
- **一句意图（可跳过）**：“这一段做什么？”单行输入，回车开始；可从待办里选。
- **专注面板只留三个标签**：**这一段**（计时 + 意图 + 便签）/ **待办** / **声音**。统计与随手记搬进「日记」，学习进实验室。
- **结束仪式：压制唱片**（新的核心时刻）
  - 卡片：当前唱片封面（一张小黑胶从唱机滑出的动画，减少动态时淡入）、这段做了什么、时长、当时的房间与天气。
  - 一个可选输入：“留一句话给这一段”（≤ 140 字）。不写也能保存。
  - 按钮：「休息一下」/「再来一段」/「收好了」。
  - 数据：在现有 `flow-cabin-focus-sessions-v1` 记录上增加可选字段 `note`（向后兼容，不升版本号），并纳入备份。
- **不惩罚**：暂停、跳过、提前结束都不扣任何东西；不足 5 分钟的中断不生成唱片，也不显示失败。

### 6.4 唱片日记（原「小屋日记」重做）

- **主视图：这一周**。按天排列“压制”的唱片（封面小黑胶 + 意图 + 一句话），点开看详情。
- **本周合集（B 面）**：周日自动生成一张卡片：本周专注时长、陪你最久的三张唱片、你写下的一句话、一句歌词（如有）。可导出图片——替代明信片。
- **一年唱片墙**：替代热力图——每天一格，用当天陪伴最久的唱片封面主色填色。
- **随手记、手记**并入这里（同一个列表里的“文字条目”）。
- **连续天数 → 本周几天**：用“本周来了 3 天”代替“连续 N 天”，每周自然归零、永远不会“断”。

### 6.5 奶糖（灵魂层）

- **陪伴而非索取**：专注时它做安静的事（趴在书上、看窗外、跟着歌轻轻点头）；休息时伸懒腰；结束时开心一下。
- **气泡减半**：只在开始、结束、回访三个时刻出现。
- **不再要求喂食**：喂食保留为可选互动，但“讨食 / 有点蔫”不再主动出现（Phase 2 起心情不再随时间下降）。
- **Phase 2：情境瞬间**（借鉴 Spirit City 的精灵）：房间 × 天气 × 时段 × 唱片风格触发 20–40 个“奶糖瞬间”，收进日记的相册。零货币。
- **Phase 2：出门**：一天专注满 60–90 分钟后，奶糖出门，下次打开带回一样东西（一首它“在路上听到的歌”、一张窗景）。

### 6.6 成长：只有一个累计量

- **小屋时光** = 累计专注时长（听歌时长作为次要加成，可选）。
- 里程碑（5 / 20 / 50 / 100 / 300 小时…）让房间**自己**变暖：多一盏灯、一盆植物长大、窗外换季、奶糖新配饰。**自动发生，不需要购买。**
- 小鱼干：Phase 1 不动数据，只是降低曝光；Phase 2 评估并入“小屋时光”（迁移时余额全部保留并折算）。
- 纪念物：Phase 2 并入里程碑与奶糖瞬间。

## 7. 视觉语言：高级温馨

**方向**：以 v2.1 手绘暖光场景为准（它是最成熟、最有辨识度的资产），UI 退后一步，让画面说话。

| 维度 | 规则 |
|---|---|
| 层级 | 每屏只有一个主角（首页 = 房间；唱片架 = 封面；专注 = 时间；日记 = 唱片）。其他元素降低对比度 |
| 面板 | 暖色半透明“木纸灯”面板：深胡桃底 + 轻微毛玻璃 + 1px 暖金描边 + 柔和阴影；统一 12px 圆角（按钮 8px、胶囊 999px） |
| 色彩 | 沿用 `--px-*` 色板作为原色，新增语义 token（`--ui-surface`、`--ui-line`、`--ui-text-*`、`--ui-accent` 等）；强调色只用琥珀一种 |
| 字体 | 正文：HarmonyOS Sans（已打包）；标题与歌词：同一字体的轻/中字重拉开层级；**像素字体只留给计时数字与少量装饰**，不再用于按钮和正文 |
| 字号 | 12 / 13 / 15 / 18 / 24 / 32 / 48，行高 1.5（正文）/ 1.2（标题） |
| 动效 | 220–320ms、`cubic-bezier(.2,.8,.2,1)`；只动 transform / opacity；全部有减少动态回退 |
| 标签 | 家具不再常驻文字标签；悬停才出现 |
| 留白 | 面板内边距 20/24px；列表行高 ≥ 44px |

## 8. 性能与信任（高级感的底线）

调研中 Spirit City 的第二大差评是占用高，Finch 的最大差评是丢数据。

- 窗口被遮挡 / 最小化 / 沉浸覆盖时，房间渲染暂停（现有机制保留并加测试）。
- 专注中后台常驻：目标 CPU < 3%（M 系列 Mac），不跑无意义的动画帧。
- 任何数据不会因为不活跃、版本升级、功能隐藏而被清除。实验室开关只影响入口。
- 每次升级前自动恢复点（现有机制保留）。

## 9. 衡量“做对了”

本地优先、没有遥测，所以用可验证的体验指标 + 自用记录：

| 指标 | 目标 |
|---|---|
| 新用户从打开到听到声音 | ≤ 60 秒（本地 / 内置示例） |
| 回访用户从打开到继续播放 | 1 次点击 |
| 开始一段专注 | 1 次点击（从首页任意状态） |
| 结束一段后留下记录 | 0 次必填输入 |
| 一级入口数量 | 3（+设置） |
| 专注面板标签 | 3 |
| 设置分区 | 6 |
| 首页常驻文字标签 | ≤ 3 |

## 10. 路线图

### Phase 1 · 收束（本次，多代理并行）
