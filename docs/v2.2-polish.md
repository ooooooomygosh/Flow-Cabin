# Flow Cabin 2.2 打磨记录

基线：v2.1.0（`99749b3`）。2.2 不再新增大功能，而是把每条日常路径打磨到同类产品的水准：打开就是小屋，听歌、看歌词、换角落、专注、照顾伙伴都顺手、不闪、可撤销。对标对象：歌词与播放器对标网易云音乐 / QQ 音乐 / Apple Music，专注对标 Session / Flow / Forest，桌宠对标 Shimeji / BongoCat，整体外壳对标 Things 3 / Notion。

## 首页与外壳（M0、M6）

| 改动 | 说明 |
| --- | --- |
| 生活小屋转正 | 新安装和没有主动选过首页的用户进入小屋；明确选过原版的用户保留原版。首次进入有一张可关闭的「首页换成了生活小屋」卡片，一键「改用原版」。去掉所有 Beta 字样，首页选择并入「设置 › 房间与桌宠」。 |
| 统一返回 | `src/ui/back-stack.mjs`：Esc 和 Android 返回键每次只退一层（对话框 → 角落 → 布置模式 → 筛选弹层 / 二次确认 / 智能唱片机）。 |
| 提示条 | 排队显示、悬停暂停、错误保留更久、可带「撤销」；位于顶层，模态对话框打开时渲染在最上层对话框内，按钮依然可点。从唱片架移除可撤销，原 id 恢复。 |
| 首次引导 | 6 步减为 3 步（音源 → 房间与伙伴 → 试听），权限折叠在最后一步；版本更新改为一次性「新功能」页。小屋首页也会出现引导。 |
| 设置 | 搜索框（Ctrl/⌘+F，回车跳到结果并高亮）；`?` 或 Ctrl/⌘+/ 打开快捷键速查表。 |
| 诊断与配方 | 功能诊断全部改为中文说明和下一步建议；场景配方有空状态、上限提示和撤销。 |

| 资源 | 8 张全屋图改为无损 WebP（17.96 → 12.03 MB，逐像素一致）；Android 包排除从不加载的宣传素材、未用字重和桌面图标，`dist-android` 约 255 → 190 MB。 |

## 歌词（M1）

| 改动 | 说明 |
| --- | --- |
| 匹配 | LRCLIB 先精确查找，再按「标题去掉 Remastered / feat. / 括号版本说明、全角半角统一」「歌手集合」「时长 ±2/5/10 秒」打分搜索；现场、伴奏、Remix、翻唱永远不会被当成同一版本。最多列出 5 个相近版本，「歌词不对？换一版」一键切换并记住选择。找到的歌词在磁盘缓存 7 天，离线可用。 |
| 平台歌词 | 网易云取逐字 YRC 及与之对齐的翻译、罗马音；QQ 在拿到可读 QRC 时使用逐字。翻译 / 罗马音按 0.5 秒内最近的一行对齐。 |
| 房间皮肤 | 八个主题各有一套歌词皮肤（配色、字体、进场动画、粒子）：像素块、壁炉火星、墨水、萤火虫、浪花、星点、车窗雨滴、花瓣。粒子随音乐能量和节拍律动，专注时和减少动态时自动收敛。 |
| 沉浸歌词 | Apple Music 式全屏：左侧封面、进度和控制，右侧 AMLL 弹性歌词；背景是当前房间听歌角模糊图叠加封面取色，伙伴在角落跟着点头。3 秒无操作隐藏控件；空格、←/→、T（翻译）、R（罗马音）、[ ]（±0.1 秒）。设置面板：偏移 ±0.5 秒、「听到下一句开头时点这里对齐」、字号、翻译、罗马音、粒子、换版本、导入 / 清除。手机竖屏自动改为上下布局。 |
| 歌词册 | 房间里的歌词册用纸面墨色版皮肤逐字填色唱出当前句。 |
| 桌面歌词 | 网易云 / QQ 式悬浮歌词条：透明、置顶、按显示器记住位置、重启后恢复；KTV 双行交错或单行居中；逐字填色由自己的时钟插值；跟随小屋或纸灯 / 霓虹 / 素白样式；能量 / 节拍光晕；可显示伙伴。悬停工具条：上一首 / 播放 / 下一首、字号、样式、翻译、单双行、伙伴、锁定、关闭。锁定后鼠标穿透，只有悬停解锁按钮时可点。托盘菜单与全局快捷键可开关、可锁定。 |
| 数据通路 | 页面发布一个带版本号的歌词源：整首歌词只在变化时传一次，其余时间只传墙钟锚点，取代原来每 350ms 用脚本读一行文本。 |
| 歌词副屏 | 另一台设备上逐字唱出当前附近几句，使用发送端房间的皮肤；时间只用同一时钟上的差值计算，不依赖两台设备的时钟一致。消息有界，最坏情况也小于 128 KiB。 |
| 迷你唱机 | 显示当前这一句。 |

## 角落切换（M2）

- 从全屋走进角落：镜头向该角落家具实际所在位置推近（约 320ms），同时解码近景图，再交叉淡入；退出时反向。减少动态时为 120ms 淡入淡出。
- 全屋地板上的区域可直接点击，悬停显示名称；家具热点优先。
- 三个角落横排成一条：手指 / 鼠标拖动 1:1 跟随，按速度吸附，两端有回弹；桌面边缘箭头、←/→、1/2/3、0 或 Esc 返回全屋、触控板横向滑动；底部带名称的分页点。
- 空闲时预取并解码当前主题的三张近景，切换不再出现「正在走进这个角落…」；换主题时暗化旧房间，新图就绪前不显示家具标签。
- 记住上次所在区域；角落和全屏弹层盖住全屋时暂停 Pixi 渲染；加载失败可重试。

## 播放器（M3）

- 重启后回到上次的唱片、曲目和进度（暂停状态，只保存曲目身份不保存临时音源）；切换首页后若正在播放会继续播放。
- 系统媒体控件：上报进度，支持快退 / 快进 / 停止，本地封面转为 data URL，歌单歌曲显示自己的歌手和专辑。
- Apple Music / Music Assistant 来源不再显示无效的进度和音量；系统来源显示只读进度，空格 / Shift+方向键可控制。
- 拖过滑块后空格仍可用，方向键按 5 秒步进。
- 单曲「下一首播放 / 加入队列」，队列可拖动排序、清空、立即播放；随机模式下「上一首」回到真正听过的上一首，并有「最近播放」。
- 不可播放的歌标灰并说明原因，自动跳过时提示一次；目录搜索加入的专辑自动建议音源。
- 迷你唱机：修复把环境音当成在播放的问题；真实封面、歌手、进度、音量、歌词；可拖动、记住位置、可置顶，不再只在沉入桌面时出现。
- 全局媒体快捷键（可在设置中改）、菜单栏「控制」菜单、Windows 任务栏缩略图按钮、macOS Dock 播放菜单；音量感知曲线、滚轮调节与百分比；本机「喜欢」。

## 专注与任务（M4）

- 专注中关窗会隐藏到托盘 / 菜单栏继续计时；专注中退出需要确认。
- 结束提醒：桌面系统通知有声音、点击回到小屋（macOS 带「开始休息 / 跳过」）；四种提示音和音量；手动跳过不响。Android 扩展原有专注闹钟为精确闹钟并提高通知级别。
- 「+5 分钟」和到点后继续计时的超时模式；锁屏 / 休眠时暂停，回来询问「刚才在专注吗？」；轮次按天 / 长休息重置。
- 全局快捷键 Ctrl/⌘+Alt+F 开始 / 暂停、Ctrl/⌘+Alt+G 跳过；沉浸模式结束后可直接「开始休息 / 再来一轮 / 完成任务」。
- 任务：今天 / 之后、预估番茄数、子任务、未完成顺延；完成当前任务自动选下一项。
- 托盘显示倒计时、暂停、休息与超时；一键记录分心并进入统计；喝水提醒在后台以系统通知提醒。

## 桌宠（M5）

- 修复：「有点蔫」情绪被过滤、免打扰永远开不了、在桌宠上摸摸不计入情绪。
- 气泡只在开始、过半、最后 1 分钟、结束等时刻短暂出现，不再整轮挡住下面的应用，可关闭。
- 「隐藏 1 小时」、Windows 全屏应用时自动隐藏（辅助程序未在本环境编译）、重启后恢复出门状态。
- 可选重力落地、跨相邻显示器行走；透明度、锁定位置、始终鼠标穿透；情绪体现在姿态上，偶尔讨食或求关注（遵守免打扰）。所有桌宠设置集中在「设置 › 房间与桌宠」。

## 其他功能（M7）

学习发音（系统语音，P 键）与 CSV / Anki 文本导入；书架显示今日待复习、信箱显示未读、相框显示自选照片；手记搜索支持多词与 #标签；设备联动状态与失败原因改为中文、场景改为按钮组；智能唱片机显示分步进度并可取消、失败先说明原因；明信片逐项预览要显示的内容。

## 边界（未实测）

- 未编译、未在真机运行：Android（Java 改动、精确闹钟、通知按钮）、Windows 全屏检测辅助程序、macOS 通知按钮与菜单栏标题。APK 体积未实测（`dist-android` 约 190 MB，距 80 MB 目标仍远，需要有损压缩近景图或在 Android 上取舍原版首页素材）。
- 真实平台账号下的逐字歌词（网易云 `lyric_new`、QQ 可读 QRC）未用真实账号验证；LRCLIB 只用固定响应验证。
- 歌词副屏在真实双设备 Wi-Fi 下的同步精度未实测。
- 浏览器中「切换首页后继续播放」可能被自动播放策略阻止；Electron 不受影响。
- 实测中仍有少量与时序相关的偶发失败（桌宠打字反应、猫跳计时），重跑通过，未改动断言。
