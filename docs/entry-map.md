# 入口与模式对照表

原则：每个按钮只做一件事；空格、托盘和播放键在任何模式下都只管音乐的播放 / 暂停。

| 模式 | 进入 | 退出 | 说明 |
| --- | --- | --- | --- |
| 沉浸（整窗专注画面：翻页钟、唱片计时等） | 工具条「沉浸」、`Z` 或 `F`、专注面板里的「沉浸」；**开始专注（任何方式开始一轮，包括下一轮自动开始）时自动进入**，可在 设置 › 专注工具 › 专注画面 里关掉「开始专注时自动进入沉浸」 | `Esc`、点空白处、底栏「返回小屋」；暂停或一轮结束时弹出「返回小屋 / 留在这里」 | 底栏「开始 / 暂停 / 继续专注」只管番茄钟；画面样式用底栏的标签切换；`←` `→` 是上一首 / 下一首 |
| 唱片计时（沉浸里的一种画面） | 底栏选「唱片计时」 | 同沉浸 | 唱片标签是当前专辑封面（没有封面时用像素封套），只在音乐播放时转、唱臂随播放抬起 / 落下；点唱片 = 播放 / 暂停音乐，唱片两侧悬停出现 ‹ › 切歌 |
| 收起工具 | 工具条「收起工具」、`H` | 「恢复工具」、`H`、`Esc` | 只隐藏界面工具，留下房间和小时钟；不打开专注画面，也不影响番茄钟 |
| 唱机特写 | `T`、唱机上的唱片图 | `T`、`Esc` | 打开时是模态的：`Z` / `F` / `H` 不生效 |
| 小屋日记 | `L`、统计卡片里的「打开小屋日记」、`cabin:open-journal` | `Esc` | 在沉浸里打开时，先退出沉浸，再打开日记（日记在房间之上，不叠在沉浸上） |
| 设置 | 标题栏 ⚙、`Ctrl/⌘+,`（快捷键只在桌面版可用） | `Esc` | |
| 沉入桌面 | 工具条「沉入桌面」、`Ctrl/⌘+Alt+D` | 托盘、双击迷你唱机、同一快捷键 | 主窗口收起；此时开始专注不会弹出沉浸 |

互斥与优先级

- 沉浸盖在最上层（收起工具时也能进入）。`Esc` 一次只退一层：先关对话框，再关沉浸，再恢复工具，最后才请求退出全屏。
- 唱机特写或任何对话框打开时，开始专注**不会**自动进入沉浸，不打断你正在做的事；番茄钟照常计时，结束时照常提醒。之后按 `Z` 随时进入。
- 番茄钟在沉浸外结束或暂停，不会弹窗；只有在沉浸里才会出现「返回小屋 / 留在这里」。
- 「留在这里」后重新开始一轮也不会重复弹出。

## 菜单栏 / 托盘 与 Dock（v1.18）

| 位置 | 显示 | 操作 |
| --- | --- | --- |
| macOS 菜单栏（常驻） | 图标随状态切换（专注 / 暂停 / 播放 / 小猫，美术 PR #59 `trayTemplate-*`）；专注或休息时图标旁显示剩余时间 `24:59` | 菜单：状态行、播放/暂停音乐、下一首、开始番茄钟 / 暂停 / 继续专注、喂小猫一条小鱼干、打开小屋日记，以及原有项 |
| Windows 托盘（伙伴在外、沉入桌面或专注进行时） | 同上图标（`tray-*.ico`），悬停提示剩余时间 | 同上菜单 |
| macOS Dock | 专注时角标显示剩余分钟、图标下进度条；专注结束弹跳一次 | — |
| Windows 任务栏 | 专注时进度条 + 叠加专注小图标；专注结束且窗口不在前台时闪烁 | — |
