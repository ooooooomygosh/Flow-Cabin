# 入口与模式对照表

原则：每个按钮只做一件事；空格、托盘和播放键在任何模式下都只管音乐的播放 / 暂停。

## 书桌上的入口（3.1）

| 入口 | 位置 / 按键 | 打开什么 |
| --- | --- | --- |
| 唱机 | 后沿左边的铜牌、`C` | 抬头看唱机的控制面板：屏幕（曲名、歌词；点它打开唱机特写）、电平表、音量旋钮、随机 / 循环拨杆、台灯与环境音推子、待播与上一首 / 播放 / 下一首按键、音源钥匙；下方纸条有错误提示、换一版、取下唱片、打开唱片架、唱机特写、歌词册 |
| 台钟 | 后沿中间的红色 LED 钟 | 四个键切换显示：时钟 / 日期 / 音乐 / 专注；点钟面按当前显示打开番茄钟、待办或唱机控制面板 |
| 信箱 | 后沿右边的红色信箱、`N` | 抬头看信箱：欢迎信、版本信、需要留意的提示；开启「小屋来信」后，小屋寄来的信也在这里。↑ ↓ / PageUp PageDown 翻信 |
| 唱片架 | 右上角铜牌、`A` | 抬头看书柜：活页夹 = 唱片盒，索引本 = 全部唱片；下层台历 → 待办、便签本 → 随手记、座钟 → 番茄钟、邮筒 → 唱片日记（开启「小屋来信」时直接到信件页）；底部铜牌：添加到唱片架 / 专辑墙 / 音源与账号 / 回到书桌 |
| 唱片封套 | 桌面上 | 单击选中；双击、回车或拖到唱机上播放；焦点在封套上时 PageUp / PageDown 翻下一叠 |
| 唱机与纸条 | 桌面右侧 | 点唱机播放 / 暂停（空着时打开唱片架）；纸条上有上一首 / 播放 / 下一首与进度；「唱机特写」打开整窗唱机 |
| 抽屉 | 前沿的铜拉手、`D` | 唱片日记、伙伴、随手记、窗外与天气、备份与恢复、设置；实验室开启后另有词书、明信片、场景配方、睡前模式 |
| 纸包 | 桌面上 | 折起的纸（任何弹出的纸都能从纸角「折起」）；点它重新打开 |

抬头看书柜、控制面板或信箱时，`Esc`、点画面空白处或「回到书桌」都会低头回到桌面。抬头时 `A` / `C` / `N` / `D` 不生效。

## 模式

| 模式 | 进入 | 退出 | 说明 |
| --- | --- | --- | --- |
| 沉浸（整窗专注画面：红色台钟或唱片计时） | `Z` 或 `F`、专注计时单里的「沉浸专注」；在「设置 › 专注 › 专注画面」打开「开始专注时自动进入沉浸」后，开始专注（任何方式开始一轮，包括下一轮自动开始）也会进入（默认关闭） | `Esc`、点空白处、底栏「返回小屋」；暂停或一轮结束时弹出「返回小屋 / 留在这里」 | 底栏「开始 / 暂停 / 继续专注」只管番茄钟；画面样式用底栏的标签切换；`←` `→` 是上一首 / 下一首 |
| 唱片计时（沉浸里的一种画面） | 底栏选「唱片计时」 | 同沉浸 | 唱片标签是当前专辑封面（没有封面时用像素封套），只在音乐播放时转、唱臂随播放抬起 / 落下；点唱片 = 播放 / 暂停音乐，唱片两侧悬停出现 ‹ › 切歌 |
| 收起工具 | `H`；全屏时工具条上的「收起工具」 | 「恢复工具」、`H`、`Esc` | 收起桌上的唱片封套和抽屉，留下唱机、纸条和台钟；不打开专注画面，也不影响番茄钟 |
| 唱机特写 | `T`、唱机下的「唱机特写」、控制面板的屏幕 | `T`、`Esc` | 打开时是模态的：`Z` / `F` / `H` 不生效 |
| 唱片日记 | `L`、抽屉里的「唱片日记」、`cabin:open-journal` | `Esc` | 在沉浸里打开时，先退出沉浸，再打开日记（日记在书桌之上，不叠在沉浸上） |
| 设置 | 抽屉里的螺丝刀「设置」、托盘「小屋设置…」 | `Esc` | 桌面版的 `Ctrl/⌘+,` 打开的是「显示与字体」窗口 |
| 沉入桌面 | 「设置 › 桌面 › 沉入桌面」、`Ctrl/⌘+Alt+D`、托盘 / 「查看」菜单 | 托盘「浮出桌面」、双击迷你唱机、同一快捷键 | 主窗口收起，桌面上显示书桌和台钟；此时开始专注不会弹出沉浸 |

互斥与优先级

- 沉浸盖在最上层（收起工具时也能进入）。`Esc` 一次只退一层：先关对话框，再关沉浸，再恢复工具，最后才请求退出全屏。
- 唱机特写或任何对话框打开时，开始专注**不会**自动进入沉浸，不打断你正在做的事；番茄钟照常计时，结束时照常提醒。之后按 `Z` 随时进入。
- 番茄钟在沉浸外结束或暂停，不会弹窗；只有在沉浸里才会出现「返回小屋 / 留在这里」。
- 「留在这里」后重新开始一轮也不会重复弹出。

| 位置 | 显示 | 操作 |
| --- | --- | --- |

| macOS Dock | 专注时角标显示剩余分钟、图标下进度条；专注结束弹跳一次 | — |
| Windows 任务栏 | 专注时进度条 + 叠加专注小图标；专注结束且窗口不在前台时闪烁 | — |

## 桌宠小猫（伙伴出门后在桌面上的那只）

| 操作 | 结果 |
| --- | --- |
| 单击小猫 | 摸摸：小猫开心一下（庆祝动作 + 一句话），计入心情「摸摸」 |
| **双击小猫**（350 ms 内点两下，不拖动） | **蹦一下**：播放 6 帧跳跃动作（`HOP_POSE`，约 0.6 秒），然后回到原来的姿势。第一下照常算一次摸摸 |
| 按住拖动 | 小猫跟着鼠标走，可以放到**任何位置**：任一显示器、屏幕边缘、Dock / 任务栏上方、菜单栏下方。松手就停在那里（不再掉到屏幕底部）；用力甩出去会滑一段、碰到边缘弹回，停下的地方就是新位置 |
| 右键 | 菜单：**喂一条** · 开始 / 暂停专注 · 开关小屋声音 · 大小 · 打开小屋 · 让伙伴回家 |
| 右键「喂一条」，或把小猫面板里的小鱼干**拖到桌面小猫身上** | 和面板里「喂一条」一样：花 1 条小鱼干、心情 +12，桌面小猫播放 6 帧进食动作（`EAT_POSE`，放两遍约 2 秒）。没有鱼或今天已喂满时，小猫冒出原因提示，不扣鱼 |
| 位置 | 记在 `pet.json`，下次出门回到原处；拔掉显示器或改分辨率后，自动挪回最近一块屏幕的可用区域内 |
| 键鼠陪伴（「设置 › 小屋与奶糖 › 键鼠陪伴」，默认开；伙伴出门后生效） | 任何应用里的键盘按下与鼠标点击都会让奶糖响应，分别播放 `typing` 与 `click`，停手后回到原来的动作。只接收事件类型与时间戳，按天在本机累计次数；不记录按键、鼠标按钮、坐标、窗口标题或目标程序。macOS 只需在「隐私与安全性 › 输入监控」授权，使用 HID listen-only tap；应用回到前台会重新检测，关闭或未授权时只响应小屋窗口里的输入 |

抽屉里的「伙伴」打开小猫面板（喂一条、换配饰、选择伙伴）。
