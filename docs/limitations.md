## 专注、桌面与安装包

- 番茄钟、待办、随手记、统计、离线环境音／Lo-fi、沉浸模式已实现。Mac 已完成真实一分钟专注，包括隐藏与重启后继续；浏览器中的模拟时钟回归另行标注，不代替这一结果。
- Mac 桌宠启停、置顶与同步已验证；用户另行确认点击透传与拖动。该人工确认补充早期报告的「未完成」，不把桥命令测试算作系统输入验收。
- Mac 动态背景启停、取消、故障恢复与两个屏幕分别启动已验收。Spaces／全屏切换、热拔插、同时铺满两屏未验证；所有工作区属性不能作为实际行为证据。
- v1.8.0 的 Mac arm64 / x64 DMG、ZIP 及 Windows x64 安装／便携产物已成功打包，并完成打包客户端检查。打包或客户端启动成功不等于每种 OS 的播放、桌宠与动态背景均通过真实设备验收。Windows ARM64 和 Linux 不在当前下载承诺内。
- macOS 当前采用临时签名，未完成开发者身份签名、公证与 hardened runtime 配置。Windows 也未建立可信发布者签名保证。安装说明见[上手指南](getting-started.md#安装与首次打开)。

## 本地数据与网络

收藏、外观、笔记、专注记录、待办和随手记在本机保存。备份可迁移这些内容，不能作为音乐登录会话迁移工具。

曲库搜索、封面加载与平台音乐访问第三方；「本地保存」不是「所有功能离线」。safeStorage 不可安全加密时拒绝持久保存凭据；动态桌面和桌宠只接收清洗后的显示数据。Music Assistant 更换服务器清除旧凭据，退出登录使进行中的播放请求失效。

本地文件目录边界、封面重定向校验与音频 URL 白名单是已有防护实现，不构成无漏洞保证。[架构与信任边界](architecture.md)保留具体说明。
