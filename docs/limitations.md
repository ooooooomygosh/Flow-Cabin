## 手记、来信与备份

- 手记和**整组往来信**只能从回收站永久删除，并需要第二次确认。普通移除仍可恢复。
- 永久删除后只保留 `{ id, purgedAt }` 标记，正文、标签、历史和回信正文不再保存；旧窗口、旧草稿和迟到回信不能复活内容。
- 备份格式为 v4：保留删除标记，但不包含已删除正文。没有删除记录的**新 profile** 仍可导入外部旧备份；外部旧备份不能推断或撤销从未记录过的永久删除。
- 纪念物独立保存，不因清理手记、整组信件或信箱回收站而消失。
- 收藏、笔记、专注记录、待办、随手记、手记与信件保存在本机。备份用于本机迁移和恢复，不是音乐登录会话或云端同步工具。

“可恢复移除”和“永久删除”必须保持不同语义。此后修改删除、备份或回信流程时，应同时验证旧窗口、迟到回信、旧备份和跨 profile 恢复。

## 桌面、原生与安装

- v1.18.0 是当前稳定发布版本；当前工作分支的新增内容尚不代表正式发布。
- 2026-10-19 已在干净临时目录生成 `1.19.0` Apple Silicon（arm64）开发包。`codesign --verify --deep --strict` 通过，ASAR 包含本地 `node-forge` 加密适配层；使用真实 Electron 与隔离 profile、未启用 mock keychain 的备份验收完成 4 项流程与 72 项逐域比较。该包仍为 ad-hoc 签名，不能替代正式签名、公证或同路径升级验收。
- **v1.17.0 → 当前版本的同安装路径安装器升级尚未验证。** 还缺同 profile 替换、重启和逐域数据比较；旧包存在或校验通过不等于升级验收通过。
- macOS 当前屏幕处于锁定状态，因此真实键鼠、原生焦点和全天原生验收未完成。此前双屏测试已记录原生窗口焦点失败；网页获得焦点不能替代系统焦点。
- Windows、Intel Mac、真实 QQ / 网易云 / Apple Music 账号、全局输入权限和原生壁纸挂载均未完成实机验收。
- 桌面模式、桌宠和全屏有实现与部分隔离验证；打包或应用启动成功不等于每个系统上的桌宠拖动、输入穿透、壁纸层和退出恢复都通过。
- macOS 当前使用 ad-hoc 签名，未完成 Apple Developer 签名、公证与 hardened runtime；Windows 未建立可信发布者签名。自动更新器也没有端到端验收。

因此，本分支不能宣称“完整原生验收通过”“安装器升级通过”或“已公证发布”。在这些证据取得前，相关项目继续标为未完成。

## 本地数据与网络

曲库搜索、封面加载与平台音乐访问会连接第三方；本地保存不是所有功能离线。safeStorage 不能安全加密时拒绝持久保存凭据；动态桌面和桌宠只接收清洗后的显示数据。Music Assistant 更换服务器会清除旧凭据，退出登录使进行中的播放请求失效。

本地文件目录边界、封面重定向校验和音频 URL 白名单是已有防护实现，不构成无漏洞保证。凭据、Cookie、个人备份与签名媒体 URL 不应出现在截图、日志或 Issue 中。
