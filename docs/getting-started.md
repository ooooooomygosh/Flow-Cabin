# 第一次来到心流小屋

心流小屋的收藏、专注和环境音无需账号。要听平台音乐，再连接自己的音乐账号或已有播放器。

## 书桌是唯一的首页

3.1 起首页是一张从上往下看的胡桃木书桌，移植自 MIT 许可的开源项目 [DEsk](https://github.com/fyzugx/DEsk)（© 2026 The DEsk authors，许可见 `public/licenses/DEsk-MIT.txt`）。原来的等距像素房间、房间切换和布置模式都已移除；收藏、专辑墙草稿、专注记录和日记都原样保留。以前选过「原版」首页的设备会自动忽略那个选择。

## 在书桌上开始

打开应用就看到书桌。桌子后沿从左到右是：

- **唱机**铜牌（`C`）：抬头看唱机的控制面板。屏幕显示曲名和歌词，旁边有电平表、音量旋钮、随机与循环拨杆、台灯和环境音推子、上一首 / 播放 / 下一首按键，以及选音源的钥匙。
- **红色 LED 台钟**：四个键切换时钟 / 日期 / 音乐 / 专注；点钟面打开对应的专注、待办或唱机。
- **信箱**（`N`）：新手引导、版本说明和需要留意的提示都以信的形式寄到这里。
- **唱片架**铜牌（`A`）：抬头看书柜。活页夹是唱片盒，A–Z 索引本是全部唱片；下层的台历、便签本、座钟和邮筒分别打开待办、随手记、番茄钟和信箱；底部铜牌是「添加到唱片架」「专辑墙」「音源与账号」「回到书桌」。

桌面上摊着唱片封套，右边是唱机：

- 听歌：双击封套、选中后按回车，或把封套拖到唱机上。焦点在封套上时按 PageUp / PageDown 翻下一叠，封套下方也有 ‹ › 按钮。唱机下面的纸条有上一首 / 播放 / 下一首和进度；「唱机特写」打开整窗的唱机近景（也可按 `T`）。
- 专注：点台钟，或在书柜上点座钟。专注是一张纸做的计时单，分「这一段 / 待办 / 随手记 / 声音」几页（开启「词书学习」后多一页「学习」）；「沉浸专注」让整个窗口变成红色台钟。
- 抽屉（`D` 或前沿的铜拉手）：唱片日记、伙伴、随手记、窗外与天气、备份与恢复、设置；实验室里打开对应功能后，还会出现词书、明信片、场景配方和睡前模式。
- 天气：抽屉里的「窗外与天气」，选择「使用当前位置」或搜索城市。系统拒绝定位后仍可手动选城。
- 收起工具：按 `H` 收起桌上的唱片和抽屉，只留唱机和台钟。

弹出的窗口都是一张纸。鼠标在右上角的纸角停半秒，纸角翻起，背面印着「折起 · 展开 · 丢掉」：折起的纸变成桌上的一个纸包，点纸包再打开；展开铺满窗口；丢掉就是关闭。

手机（窄于 700 px）上，台钟在最上面，下面一排三块铜牌（唱机 / 信箱 / 唱片架），然后是唱机和两列可滚动的封套，抽屉在最下面。

## 先在网页版坐一会儿

打开[网页版](https://album-circle.vercel.app/)，无需安装或注册。可以先手动添加一张唱片，也可以直接开一轮专注。数据保存在当前浏览器中，清理站点数据前请导出备份。

网页版收藏保存在当前浏览器，不依赖桌面收藏接口。曲库搜索需要桌面版；网页版可使用手动填写与备份导入。网页版没有 QQ / 网易云登录、Music Assistant、独立桌宠、动态桌面、自动更新或本机 Codex CLI。AI 默认关闭；启用后需要接口支持跨域，Key 未加密，仅保存在当前标签页的会话中。

## 安装与首次打开

从 [GitHub Releases](https://github.com/ooooooomygosh/Flow-Cabin/releases/latest) 下载，不要用源码 ZIP 代替安装包。

| 设备 | 选哪个文件 |
| --- | --- |
| Mac M1 / M2 / M3 等 M 系列 | 名称含 `mac-arm64` 的 DMG（ZIP 也可） |
| Intel Mac | 名称含 `mac-x64` 的 DMG（ZIP 也可） |
| Windows x64 | 名称含 `x64-setup.exe` 的安装版，或 `x64-portable.exe` 的便携版 |

Mac 可在「关于本机」查看芯片；Windows 可在「设置 → 系统 → 系统信息」查看系统类型。目前没有 Windows ARM64 原生或 Linux 安装包承诺。

**Mac：** 打开 DMG，把「心流小屋」拖到「应用程序」，再从那里打开。当前产物未完成开发者签名和公证。若 macOS 阻止打开，先核对文件确实来自本仓库的 Release，检查系统给出的原因；只有信任这份下载时，才使用「系统设置 → 隐私与安全性」提供的单次「仍要打开」入口。不需要关闭系统安全保护。系统没有提供入口、文件损坏或提示恶意软件时，保留提示并[反馈问题](https://github.com/ooooooomygosh/Flow-Cabin/issues/new/choose)。

**Windows：** 安装版可选目录并创建快捷方式，便携版直接运行。未建立可信发布者签名时，系统可能显示警告；先核对下载来源和完整文件名，再决定是否继续。

**更新：** 先在「设置 › 数据 › 收藏与备份」导出一份备份，再退出小屋，安装新版本。不要删除个人数据目录来解决升级问题；发生问题时保留备份与报错。

应用版本比上次看过的版本新时，启动后不会弹窗：信箱里会多一封这个版本的信，写着这次的变化；完整的版本历史在「设置 › 实验室 › 关于 › 查看新功能」。全新小屋收到的是一封欢迎信，信上的三步（选音源 / 挑伙伴 / 试听）各自打开新手引导的那一步。

## 伙伴与专注

打开「设置 › 小屋与奶糖」选一位伙伴。五位伙伴都可直接选择，无需完成任务解锁；选择保存在本机，并同步给桌宠。首页不再有场景可选。

- 抽屉里的「伙伴」是伙伴的照片，点开是它的面板：喂小鱼干、换配饰、选择伙伴。
- 点台钟打开专注。专注计时单分「这一段 / 待办 / 随手记 / 声音」几页；按 `L` 或抽屉里的「唱片日记」能看完整的专注记录和周报。每日目标在「设置 › 专注」里改。
- 专注时长可以在计时单的「计时设置」里调整。打开计时单不会自动开始；按「开始专注」才开始计时，默认留在书桌上。想让开始专注时自动进入沉浸，可到「设置 › 专注 › 专注画面」开启。
- 「提前结束本轮专注」会直接回到待机；满一分钟的已专注时间仍保留在日记中，提前结束不计奖励。
- 按 `Z` 或 `F` 进入沉浸（整窗的红色台钟或唱片计时），按 `Esc` 回来。通知或系统集成若请求新权限，可先取消；收藏与普通计时不依赖音乐控制权限。

## 收藏第一张专辑

按 `A` 抬头看书柜，点底部的「添加到唱片架」（桌上还没有唱片时，桌面上的纸条也有「添加第一张专辑」），搜索专辑或粘贴 QQ 音乐专辑链接；也可选择「手动填写」。添加后的唱片摊在桌面上：单击封套选中，双击、回车或拖到唱机上就放上唱机。封套下方的「唱片卡片」里可以看曲目、写笔记或移除收藏。

**唱机默认「仅动画展示」，没有音频。** 曲库搜索提供封面和资料，不代表对应平台授权播放。想听歌，先在「设置 › 音乐」选择实际来源；在唱机控制面板上转一下音源钥匙也能直接切换。

唱片多于一叠时，用 PageUp / PageDown 或封套下方的 ‹ › 翻页；书柜上的活页夹和索引本可以按唱片盒或按名字查找。

## 连接音乐

| 想怎么听 | 做法 | 范围 |
| --- | --- | --- |
| 播放电脑里的文件 | 「设置 › 音乐 › 账户与文件夹」添加本地音乐文件夹，导入专辑，在「设置 › 音乐」选择「本地音乐」 | 按音频标签整理；文件保留原位置，移动或删除原文件会影响播放 |
| 用 QQ / 网易云账号 | 在「设置 › 音乐 › 账户与文件夹」连接对应账号，在独立窗口登录；在「设置 › 音乐」选对应音源 | 权限以音乐平台返回为准。QQ 歌单批量导入未实现，登录不代表歌单已同步 |
| 跟着已有播放器 | 先在受支持的播放器播放，再在「设置 › 音乐」选择「系统正在播放」 | Mac 支持 Music / Spotify；Windows 依赖播放器发布系统媒体会话。不是小屋内嵌的官方流媒体 SDK |
| 用家里的音箱 | 「设置 › 音乐 › 账户与文件夹」填写已有 Music Assistant 服务器与播放器，再选对应音源 | 需要可访问的服务器和授权；真实音箱仍待验收 |
| 只想要安静的背景音 | 打开专注计时单的「声音」页，手动开启小屋声音并调音量（唱机控制面板上的「环境音」推子也能调） | 环境音和生成式 Lo-fi 可离线使用；与唱片动画展示独立 |

QQ 旧收藏若缺少音频文件标识 `mediaMid`，可能无法播放；自动补全尚未实现。先备份，重新搜索取得资料后另行添加，保留旧笔记和外观，确认新记录可用再处理旧记录。不要为了排错清空全部收藏。

没有声音时依次检查：是否仍为「仅动画展示」、是否已连接音源、平台是否允许此曲播放、音量是否静音。界面会显示当前音源的错误或状态；[反馈](https://github.com/ooooooomygosh/Flow-Cabin/issues/new/choose)时附状态文字，不要附 Cookie、令牌或签名音频链接。

## 让小屋帮你搭配唱片

先在「设置 › 实验室」打开「智能唱片机」，再点唱机控制面板或书柜上的「让小屋挑一张」，说出计划，例如「我要学习五十分钟，帮我搭配音乐」。配置 AI 后，小屋会按场景编排一张可以超出唱片架的完整歌单；可以先只收进唱片架，也可以保存后直接开始这一轮。

确认后，小屋会设置本轮专注时长，把第一张唱片放上唱机，并让其余推荐依次进入待播。你可以选「开始即播放」，也可以只把唱片放上去、稍后自己按播放。若最终没有可验证的可播放音源（例如仍是「仅动画展示」），界面不会假装小屋已经出声。

在「设置 › 实验室 › AI（Beta）」选择固定模板即可：DeepSeek 会使用 `deepseek-flash` 并关闭思考；OpenAI、OpenRouter 填入 Key；Ollama、LM Studio 可直接连接本机服务；桌面版还可以选择「本机 Codex CLI」，使用终端里已登录的 Codex，只读取最终回答。只有“自定义”模板需要自己填写接口地址。配置后，小屋会用严格 JSON 请求一张完整歌单。歌单只保存歌名、歌手与专辑，不依赖模型给出的平台 ID；播放时由自动匹配音源查找可播放版本。未配置、请求失败或返回格式不合格时，会自动改用本机按流派、标题与收藏顺序生成的唱片架推荐。请求只包含唱片摘要与你的这句话，不发送待办、日记或 API Key。技术约定见 [onboarding.md](onboarding.md)。

## 桌宠与动态桌面

「设置 › 小屋与奶糖」里的「伙伴出门」启用桌宠（托盘菜单也有同一个命令；悬停可看到伙伴的名字），再点同一个入口让它回家；桌宠可拖动，右键菜单可开始专注。「设置 › 桌面 › 沉入桌面」或 `Ctrl/⌘+Alt+D` 让小屋沉到所有窗口下面，桌面上显示书桌、红色台钟和一张写着正在放什么的纸条；同一快捷键或托盘「浮出桌面」回来。

桌面版默认开启「跨应用键鼠陪伴」。入口在「设置 › 小屋与奶糖 › 键鼠陪伴」：即使焦点不在小屋、甚至桌宠暂时没有显示，只要总开关和系统权限有效，键盘按下与鼠标点击仍会累计，并让奶糖做出打字或点击动作。鼠标单击桌宠会打开紧凑面板，可看今天的键盘 / 点击次数、连续天数与最近 7 天，也能喂小鱼干、开始专注、换配饰、调节大小与声音。

macOS 首次使用只需要授权「输入监控」。在「设置 › 小屋与奶糖 › 键鼠陪伴」里点「授予输入监控权限」，按系统提示打开开关，然后回到小屋敲几下键或点一下鼠标；「本次确认」开始增加才表示授权真正生效。这里也有「重新检测」；从 1.21.0 旧签名版本迁移且一直无反应时，才使用一次「修复输入监控授权」。

陪伴记录只统计键盘按下与鼠标点击次数，并按本地日期汇总；时间戳只用于归入当天，不保存逐次事件时间线。小屋不会读取按键内容、鼠标按钮、坐标、窗口标题或正在使用的应用，数据只保存在本机。今日计数、连续天数与 7 天趋势会出现在奶糖面板、专注统计、唱片日记和小屋来信里。

多屏时注意当前主窗口所在屏幕。已有 Mac 双屏验收只覆盖在两个屏幕分别启动／停止，不承诺同时铺满所有屏幕、热拔插或全部 Spaces／全屏行为。系统若提示新权限，先阅读提示再自行决定；完整范围见[使用边界](limitations.md)。

## 数据与备份

抽屉里的「备份与恢复」（或「设置 › 数据 › 收藏与备份」）导出收藏与专注数据，包含待办和随手记；换电脑后在同处导入。备份不是平台登录凭据的迁移工具，新电脑需重新连接音乐服务。旧 Album Circle 的本地收藏有自动迁移路径。

平台凭据通过 Electron safeStorage 保存；加密不可用时拒绝持久保存，Linux 明文回退也不接受。曲库搜索、封面和平台播放仍访问第三方；Music Assistant 更换服务器时清除旧凭据，退出登录使进行中的播放请求失效。桌宠与背景不接收登录令牌。

分享备份、截图或报错前，检查是否含个人笔记、路径、账号信息。需要排查时优先提供系统版本、应用版本、音源、操作步骤与状态文字。

## 新手引导

全新的小屋启动时不弹窗：书桌的灯亮起后，信箱里会寄来一封欢迎信。信上的三步「选音源 → 挑伙伴 → 试听（按「播放测试」才出声）」各自打开新手引导的那一步；可选权限（键鼠陪伴、通知、音乐 App、开机启动）列在最后一步里，拒绝不影响收藏、普通专注或小屋内的键鼠回应。引导可以整体跳过。

关掉引导后，下次从信箱再打开会回到同一步；「设置 › 实验室 › 关于 › 重新引导」可随时从头再走一遍并保留之前的选择。网页版不能登录平台，相关选项会标明「需要心流小屋桌面版」。状态字段、入口与智能唱片机的结构化约定见 [onboarding.md](onboarding.md)。
