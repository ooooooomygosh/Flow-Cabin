# 月夜书桌素材

`night-study.png` 是用户提供的 1448×1086 原图，用于软件小屋和动态桌面。九格架的交互位置在 `src/scene-catalog.mjs` 中标定。

以下两份衍生素材使用 Codex 内置 ImageGen 工具生成，并保留在此目录，运行时无需图像生成服务：

- `night-study-clean.png`（1448×1086）：移除书写的右手和铅笔，补全桌面和笔记本。软件仅显示原图中右手所在的小块区域，其余场景继续显示用户原图。
- `night-study-hands.png`（1254×1254，RGBA）：透明 4×4 姿态图集，保留手、绿色袖口和铅笔。软件逐帧更换姿态，不拉伸背景矩形。

生成规格 / 提示词集：

1. 以用户原图为参考，匹配日式动画线条、肤色、绿色袖口和左侧暖灯。参考书写区域约为原图 x=266…410、y=476…620。生成规则排列的 4×4、16 帧右手与铅笔姿态，统一摄影角度、腕部锚点和大小。帧 1–6 为纸面书写小动作；7–8 抬笔；9–12 以拇指为轴转笔；13–14 接笔；15–16 下笔。不得增加角色、物体或文字。
2. 编辑上述图集，去除所有桌面、笔记本和背景，仅保留每格的手、袖口和铅笔，输出真实透明背景，保持网格与姿态位置。
3. 编辑用户完整原图，仅移除约 x=286…386、y=508…580 的书写右手及笔，自然补全笔记本、桌面和袖边。保留人物其余部分、灯、窗、植物及九格柜。

播放节奏见 `src/StudyWriting.jsx`：多次短书写后抬笔、转笔、接笔、下笔；减少动态效果时保持静止。素材加载失败时保留原始静态场景。
