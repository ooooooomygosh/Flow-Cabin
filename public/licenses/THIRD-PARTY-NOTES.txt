心流小屋 · Flow Cabin — third-party notes

Bundled libraries
- Tone.js (MIT) — Web Audio framework used by the generated lo-fi radio. See Tone.js-LICENSE.txt.
- music-metadata (MIT) — reads tags from local music files in the desktop client. See music-metadata-LICENSE.txt.
- Heroicons (MIT) — interface icons. See Heroicons-LICENSE.txt.
- pixelarticons (MIT) — the repeat and repeat-one play-mode glyphs (the shuffle glyph is drawn for Flow Cabin in the same grid). See pixelarticons-LICENSE.txt.
- OpenCC (Apache-2.0), via opencc-js (MIT) — the single-character Traditional ⇄ Simplified Chinese tables in src/player/hanzi-data.mjs, generated by scripts/generate-hanzi.mjs. See OpenCC-LICENSE.txt and opencc-js-LICENSE.txt.
- SunCalc (BSD-2-Clause, (c) Volodymyr Agafonkin) — sun and moon position and moon phase for the window sky, vendored as src/sky-suncalc.mjs. See suncalc-LICENSE.txt.
- Simple Music modules (GPL-3.0-only) — QQ / NetEase playback in the desktop client; see desktop/vendor/simple-music.

Data
- Weather data by Open-Meteo.com (CC BY 4.0, https://open-meteo.com/) — only when 跟随真实天气 is switched on in the desktop app; off by default and never requested by the web build.

Design references (ideas only, no code copied)
- Skycons (CC0): clouds drawn as a few overlapping puffs.
- Weatherd / rain-on-glass demos: beads that cling and then run down the pane.
- meel-hd/lofi-engine (MIT): endless seeded lo-fi generation with Tone.js, Pomodoro, focus statistics and Zen mode.
- btahir/next-beats (MIT): an ambience mixer with independent volumes.
- Study Saga: experience, levels and focus streaks.
- Chill Pulse (Catos Game): cosy pixel room with tasks, timer and unlockable extras.
- music-assistant/server (Apache-2.0): remote player control, already used through its HTTP API.

The pixel cat, cabin overlays, ambience synthesis and lo-fi composer are original to this project.

Study tools
- ts-fsrs (MIT) — existing spaced-repetition scheduler, unchanged in this release. See ts-fsrs-LICENSE.txt.
- The Daily life, Work communication and Music life starter books contain 6 words each. Their short Chinese teaching notes were written for Flow Cabin. They are not complete examination word lists. No scraped dictionary entries or third-party audio are bundled.
