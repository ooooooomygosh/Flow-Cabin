# 真实产品预览

这些图片是 Flow Cabin 渲染器的六个房间截图，1440×900 视口，缩放到 960×600 JPEG 用于宣传页首屏。不是插画或单独复刻的 UI。

使用隔离浏览器与 `scripts/showcase-albums.mjs` 中的公开演示唱片数据，不读取真实用户资料、不登录音乐账号。艺术品来源与哈希记录在 `scripts/showcase-albums.json`；专辑封面、作品名与艺人名称的权利归各自权利人所有。房间、UI 与小猫由本项目提供。

重新拍摄可复用 `npm run screenshots:product` 的夹具、设置操作与六场景循环，将对应房间截图写回这些文件；发布前检查宣传页当前场景标签与截图一致。
